# 3-2-5-4 기준 차시 비교 점검

점검일: 2026-07-28  
비교군: 3학년 2학기 1단원 1~4차시

| 항목 | 판정 | 근거 |
| --- | --- | --- |
| 수학적 판단 | ✅ | kg·g 받아올림·받아내림과 한도 판단을 두 단계로 풉니다. |
| 한 화면 한 행동 | ✅ | 현재 단계의 값이나 판단 하나만 고릅니다. |
| 그럴듯한 오답 | ✅ | 받아올림·받아내림 누락, 한도 비교 오류, 알 수 없음이 포함됩니다. |
| 정답 확인 | ✅ | 값이 계산판에 들어가고 완성식을 본 뒤 `트럭 보기`를 누릅니다. |
| 보상 공개 | ✅ | 트럭 전후 상태와 변화 문구가 한 보상 축에 있습니다. |
| 중복 입력 방어 | ✅ | 연속 클릭·물리 더블클릭·오래된 이벤트 이월을 차단합니다. |
| 시작 버튼 | ✅ | 공용 자산과 hitbox 경계·중심 차이 0px입니다. |
| 랭킹 비활성화 | ✅ | 학생 흐름과 네트워크 요청에 랭킹이 없습니다. |

정답 경로의 수학 판단 입력은 문제당 최소·중앙값·평균·최대 모두 `2`회입니다. `트럭 보기`와 `다음`을 포함한 물리 입력은 문제당 `4`회입니다. 두 수학 입력은 각각 중간 값과 최종 관계를 판단하므로 중복 입력이 아닙니다.

P0/P1/P2 수정 항목은 모두 닫혔습니다.
