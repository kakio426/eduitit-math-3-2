# 3-2-4-4 기준 차시 비교

## 비교 결과

| 강점 기준 | 1단원 비교 차시 | 4-4 적용 | 판정 |
| --- | --- | --- | --- |
| 비교 관계가 먼저 보임 | 1-2 계산 구조 | 같은 길이의 두 막대로 색칠한 길이와 한 칸 길이를 비교 | PASS |
| 그럴듯한 오답 | 1-2 오개념 선택지 | 분모가 같은 분수와 단위분수에서 반대 기준을 고를 수 있음 | PASS |
| 정답 확인 뒤 이동 | 1-4 마지막 확인 | 더 큰 분수를 왼쪽에 둔 `>` 완성식을 본 뒤 `승부 보기`로 이동 | PASS |
| 진행감과 랜덤 보상 | 1-1 보상 변화, 1-3 진행감 | 줄다리기 선물 상자를 연 뒤 6종 이벤트 중 하나를 확인 | PASS |
| 다음 목표 | 1-4 결과 흐름 | 결과 6등급과 다음 목표 흐름 유지 | PASS |

## 입력 통계

정답 경로의 문제당 수학 판단은 1회, 물리 입력은 4탭입니다. 문제 은행 전체에서 동일하므로 수학 판단과 물리 입력의 최소·중앙값·평균·최댓값은 각각 `1/1/1/1회`, `4/4/4/4탭`입니다. 10문제 완주 기준은 수학 판단 10회, 물리 입력 40탭입니다.

## 강제 항목

- 한 화면 한 행동: 더 큰 분수 하나 고르기
- 오답 양방향: 분모가 같은 문제와 단위분수 문제에서 각각 반대쪽 선택
- 마지막 확인: 두 막대와 `>` 관계가 같은 중심축에 남은 뒤 보상 버튼 노출
- 보상: 닫힌 상태와 열린 6종이 서로 다른 512×512 이미지
- 매스몬: `diversity-reward-pack`의 호랑몬 사용 유지
- 랭킹: UI·API 모두 비활성
