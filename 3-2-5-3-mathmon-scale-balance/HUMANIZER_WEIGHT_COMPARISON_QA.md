# 2026-09-28 5·6번 학생 문구 확인

적용 범위는 새 두 문항의 질문·보기·조건·오답 안내·정답 확인 문구다. 다른 문항이나 보상 문구는 고치지 않았다.

- 질문은 “더 무거운 주머니/상자는 어느 것일까요?”로 한 가지 판단만 묻는다.
- 5번 조건은 수평 저울과 같은 무게의 추만 알려 준다. 더 많은 추라는 정답 판단을 미리 말하지 않는다.
- 6번 조건은 같은 색의 추끼리는 무게가 같고 한 개의 무게는 모른다는 사실만 알려 준다. “같은 기준으로 다시 재세요” 같은 답 선행 지시는 넣지 않는다.
- 보기의 물건 이름은 그림 아래 HTML 이름표와 같다. 6번의 “알 수 없어요”는 추의 개수만으로 정할 수 없다는 독립 반례 증명에 한정한다.
- 5번 정답 확인은 `3개 > 2개`와 가 주머니를, 6번은 빨간 추·파란 추와 추 한 개의 무게 정보 부족을 설명한다. “서로 다른 추는 비교할 수 없다”로 일반화하지 않는다.
- 정답 확인의 두 문장은 문장 경계에서 나눈다. 태블릿 오답 안내는 지시문을 가리고 같은 영역에서 18px 이상으로 보여 준다.

학생 문구는 humanizer 기준으로 짧고 직접적인 표현을 검토했다. 이 문구 확인과 자동 수학·DOM 검사는 생성 그림에 대한 사람의 육안 승인이나 검수 완료 체크를 대신하지 않는다.
