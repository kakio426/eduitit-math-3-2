# 3-2-5-3 기준 차시 비교 점검

점검일: 2026-07-28

비교군: 3학년 2학기 1단원 1~4차시

| 항목 | 판정 | 근거 |
| --- | --- | --- |
| 수학적 판단 | ✅ | kg·g, t·kg 비교와 빠진 무게추 선택을 학생이 직접 합니다. |
| 한 화면 한 행동 | ✅ | 저울을 맞출 값이나 더 무거운 쪽 하나만 고릅니다. |
| 그럴듯한 오답 | ✅ | 단위 차이, 반대 저울, 같음, 알 수 없음으로 구성합니다. |
| 정답 확인 | ✅ | 고른 값이 저울 계산판에 들어간 뒤 `저울 보기`가 열립니다. |
| 보상 공개 | ✅ | 닫힌 무게추 캡슐 → 사건 이미지 → 다음 문제 순서입니다. |
| 결과 정보 | ✅ | 오른쪽 정보 축이 수정부엉몬을 가리지 않습니다. |
| 텍스트/겹침 | ✅ | 1280×800, 1024×768 주요 상태에서 교차 0건입니다. |
| 랭킹 비활성화 | ✅ | 학생 흐름과 네트워크 요청에 랭킹이 없습니다. |

정답 경로의 수학 판단 입력은 문제당 최소·중앙값·평균·최대 모두 `1`회입니다. 보상 열기와 다음을 포함한 물리 입력은 문제당 `3`회입니다. 반복 입력은 보상 사건 확인과 다음 문제 이동이며, 수학 답을 다시 입력시키지 않습니다.

P0/P1/P2 수정 항목은 모두 닫혔습니다.
