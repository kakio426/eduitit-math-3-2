# 매스몬 자료 정리단

- 대상: 초등학교 3학년 2학기 6단원 자료
- 학습 목표: 표와 그림그래프를 보고 가장 많은 것, 한 줄의 개수, 두 줄의 차이를 읽는다.
- 배포 방식: `mathmon-engine-v1`로 빌드한 단일 `index.html` 패키지
- 원본 위치: `_lessons/3-2-6-1-mathmon-data-rangers/`

## 화면 흐름

첫 화면에서 시작한 뒤 설명 2장을 보고, 10문제를 풉니다. 문제를 맞히면 자료 불빛 보상을 보고, 마지막에는 결과 이미지와 정답 수 이미지가 나옵니다.

## 주요 파일

- `index.html`: 빌드 결과
- `cover-generated.webp`: 글자 없는 첫 화면 배경
- `title-logo-generated.webp`: 생성형 제목 아트
- `start-button-generated.webp`: 생성형 시작 버튼
- `reward-scene-generated.webp`: 보상 배경
- `result-data-*-generated.webp`: 결과 배경
- `result-title-*-generated.webp`: 결과 제목 아트
- `screenshots/`: QA 캡처
