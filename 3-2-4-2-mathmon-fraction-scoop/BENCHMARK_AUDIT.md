# 3-2-4-2 기준 차시 비교

## 비교 결과

| 강점 기준 | 1단원 비교 차시 | 4-2 적용 | 판정 |
| --- | --- | --- | --- |
| 계산 순서가 보임 | 1-2 계산 구조 | `전체 ÷ 분모` 뒤 `한 묶음 × 분자`를 현재 단계 하나씩 크게 표시 | PASS |
| 수학 판단이 조작에 드러남 | 1-2 단계 선택 | 한 묶음 수와 담을 수를 학생이 각각 고름 | PASS |
| 정답 확인 뒤 이동 | 1-4 마지막 확인 | 두 계산이 완성된 바구니를 본 뒤 `바구니 보기`로 이동 | PASS |
| 진행감과 랜덤 보상 | 1-1 보상 변화, 1-3 진행감 | 닫힌 바구니를 연 뒤 6종 이벤트 중 하나를 확인 | PASS |
| 다음 목표 | 1-4 결과 흐름 | 결과 6등급과 다음 목표 흐름 유지 | PASS |

## 입력 통계

정답 경로의 문제당 수학 판단은 2회, 물리 입력은 5탭입니다. 문제 은행 전체에서 동일하므로 수학 판단과 물리 입력의 최소·중앙값·평균·최댓값은 각각 `2/2/2/2회`, `5/5/5/5탭`입니다. 10문제 완주 기준은 수학 판단 20회, 물리 입력 50탭입니다.

## 강제 항목

- 한 화면 한 행동: 1단계는 한 묶음 수 고르기, 2단계는 분자만큼 담은 수 고르기
- 오답 양방향: 분모나 전체를 고른 경우, 한 묶음만 담은 경우
- 마지막 확인: `전체 ÷ 분모 → 한 묶음 × 분자` 완성식이 같은 중심축에 남음
- 보상: 닫힌 상태와 열린 6종이 서로 다른 512×512 이미지
- 랭킹: UI·API 모두 비활성
