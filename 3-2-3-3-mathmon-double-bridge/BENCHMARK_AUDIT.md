## 버튼 목적

| 버튼 | 누르기 전 모르는 것 | 수학적 판단 | 누른 뒤 보이는 것 |
|---|---|---|---|
| 다리 길이 선택지 | 두 배 또는 반이 되는 길이 | 지름·반지름 관계 1회 | 남은 틈·돌출 또는 잠긴 다리와 완성식 |
| 다리 보기 | 이번 랜덤 보상 | 없음, 완성식 확인 뒤 전환 | 닫힌 다리 보상 |
| 뽑기 | 힘이 얼마나 바뀔지 | 없음, 무작위 결과 열기 | 실제 다리 힘 변화 |
| 다음 | 다음 문제 | 없음, 확인 뒤 전환 | 다음 문제 또는 최종 결과 |

## 입력 수

- 정답 문제당 수학적 판단 1회, 수학 입력 1회, 전환 입력 3회, 총 4회
- 문제 은행 통계: 최소/중앙값/평균/최대 = **4/4/4/4**
- 한 판: 문제 흐름 40회 + 표지·설명 진입 3회 = **43회**

## 오개념 증거

- `DIAMETER_NOT_DOUBLED`, `DIAMETER_ONE_SHORT`, `DIAMETER_TOO_LONG`
- `RADIUS_NOT_HALVED`, `RADIUS_TOO_LONG`, `RADIUS_TOO_SHORT`
- 문제 은행을 진행하며 양방향 6종을 모두 실제로 눌러 두 화면 크기로 저장했습니다.

## 최종 판정

현재 소스·빌드·브라우저 캡처 기준으로 필수 계약과 기준 차시 대비 항목을 모두 통과했습니다. P0/P1 보완 항목은 없습니다.
