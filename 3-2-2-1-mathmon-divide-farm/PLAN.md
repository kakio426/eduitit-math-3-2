# 매스몬 나누기 농장 현재 설계

- 대상: `3-2-2-1-mathmon-divide-farm`
- 배움: 내림 없는 `(몇십몇) ÷ (몇)`
- 화면: 1280×800 기준 16:10 Stage
- 상태: 2026-07-14 판단 중심 흐름 구현 완료

## 문제 흐름

1. 십의 자리 묶음을 바구니에 직접 나눠 담습니다.
2. 같은 양이 되었을 때만 묶음 나눗셈 결과를 확인합니다.
3. 낱개도 바구니에 직접 나눠 담습니다.
4. 전체 식은 `?`로 둔 채, `묶음 나누기`와 `낱개 나누기`의 결과가 덧셈으로 모이는 모습을 보고 마지막 답을 숫자로 씁니다.
5. 정답 뒤에만 완성식과 한 바구니의 전체 수가 나타납니다.
6. 완성식 확인 뒤 학생이 `수확 보기`를 눌러 보상으로 갑니다.

## 강제 통과 기준

- 한 화면 한 행동이지만, 화면마다 수학적 판단이 있어야 합니다.
- 답을 정하기 전에는 바구니에 정답 채소를 보여 주지 않습니다.
- 학생이 모든 당근을 직접 옮겨 만든 분배 상태를 검사합니다.
- 분배 오답은 서로 다른 바구니 상태를 그대로 두고 다시 옮겨 고치게 합니다.
- 마지막 덧셈 오답은 쓴 수를 그대로 보여 주고 `다시 더해 봐요.`만 안내합니다.
- 십의 자리 단계의 선택·지시·확인 값은 묶음 개수 `2`가 아니라 실제 값 `20`입니다.
- 마지막 확인과 완성식이 보상창에 즉시 가려지지 않아야 합니다.
- 랜덤 수확과 빈손 없는 결과를 유지합니다.

## 제품 선택

- 문제 화면에는 브랜드, 단원, `1/10`만 작게 둡니다. 수확판이나 농장 지도를 추가해 현재 판단을 가리지 않습니다.
- 전국 순위는 현재 제품 정책에 따라 학생 화면과 네트워크 흐름에서 비활성화합니다.
- 스마트폰 세로, 저장형 도감, 다른 차시 수정은 범위 밖입니다.
