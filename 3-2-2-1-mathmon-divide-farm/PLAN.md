# 매스몬 나누기 농장 현재 설계

- 대상: `3-2-2-1-mathmon-divide-farm`
- 배움: 내림 없는 `(몇십몇) ÷ (몇)`
- 화면: 1280×800 기준 16:10 Stage
- 상태: 2026-07-14 판단 중심 흐름 구현 완료

## 문제 흐름

1. 십의 자리 값 전체를 바구니 수로 나눕니다.
2. 학생이 한 바구니의 **실제 값**을 숫자로 씁니다.
3. 정답 뒤에만 모든 바구니가 학생의 답대로 채워집니다.
4. 낱개를 같은 방식으로 나눕니다.
5. 두 값을 합쳐 전체 몫을 직접 씁니다.
6. 완성식 확인 뒤 학생이 `수확 보기`를 눌러 보상으로 갑니다.

## 강제 통과 기준

- 한 화면 한 행동이지만, 화면마다 수학적 판단이 있어야 합니다.
- 답을 정하기 전에는 바구니에 정답 채소를 보여 주지 않습니다.
- 반복 배치는 학생이 답을 낸 뒤 시스템의 확인 애니메이션으로 처리합니다.
- 오답은 학생이 쓴 값이 모든 바구니에 들어간 상태로 보여 줍니다.
- 적으면 `남아요`, 많으면 `부족해요`로 현재 전체와 비교합니다.
- 십의 자리 단계의 선택·지시·확인 값은 묶음 개수 `2`가 아니라 실제 값 `20`입니다.
- 마지막 확인과 완성식이 보상창에 즉시 가려지지 않아야 합니다.
- 랜덤 수확과 빈손 없는 결과를 유지합니다.

## 제품 선택

- 문제 화면에는 브랜드, 단원, `1/10`만 작게 둡니다. 수확판이나 농장 지도를 추가해 현재 판단을 가리지 않습니다.
- 전국 순위는 백엔드 계약과 추가 화면이 필요한 P2 선택 기능으로 남깁니다.
- 스마트폰 세로, 저장형 도감, 다른 차시 수정은 범위 밖입니다.
