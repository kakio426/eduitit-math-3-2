## 3. 화면별 확인

### 설명 2 — 농장을 키우는 이유

- [x] `10문제를 풀고 농장을 키워요.` 한 문장만 보인다.
- [x] `씨앗 → 새싹 → 텃밭 → 농장 → 대농장 → ?` 순서가 한눈에 보인다.
- [x] 황금밭 이름은 미리 공개하지 않고 빛나는 `?`로 남긴다.
- [x] 생성 포스터의 단계 수·순서·한글 철자를 전수 확인했다.

### 문제 화면

- [x] 배경은 채소·바구니·여우몬·완성된 학습 물건·UI 패널이 없는 조용한 작업대다.
- [x] 실제 바구니와 채소는 학생 답에 따라 DOM 생성 이미지로만 나타난다.
- [x] 작은 현재 농장 배지만 있고 내부 수확값과 다음 목표는 없다.
- [x] 큰 식, 현재 카드 조작판, 한 줄 지시문이 학습 주인공이다.
- [x] 적은 답·많은 답·10의 배수가 아닌 답을 각각 현재 물건으로 설명한다.
- [x] 마지막 정답은 완성식과 함께 충분히 보인다.

### 보상 화면

- [x] 레거시 문제 위 팝업을 사용하지 않는다.
- [x] 닫힌 상태에는 현재 농장, 닫힌 바구니, `바구니 열기`만 보인다.
- [x] 사건은 학생이 열었을 때 한 번만 적용된다.
- [x] 변화량과 다음 목표는 한 번에 한 줄만 보인다.
- [x] 증가·감소·0·단계 상승·단계 하락·정답 수 제한·황금밭을 강제로 재현했다.
- [x] `prefers-reduced-motion`에서는 이동 모션을 제거한다.

### 결과 화면

- [x] 공통 `result-scene`이 아니라 6단계별 `result.image`를 실제 배경으로 쓴다.
- [x] 농장 이름·다음 목표·정답 수·순위 보기·다시 하기만 보인다.
- [x] 내부 수확 숫자와 게이지는 결과의 주인공이 아니다.
- [x] 씨앗부터 황금밭까지 6단계를 모두 강제 렌더해 자산을 확인했다.
- [x] `다음엔 새싹!`부터 `황금밭을 찾아봐요!`까지 생성형 타이틀을 사용한다.
