# 매스몬 피자 분수 가게 제작 보고

## 이번 개편

- CSS 패널 중심의 드래그 화면을 이미지형 피자 가게 무대로 바꿨습니다.
- 한 화면 한 행동을 `피자를 보고 알맞은 분수 고르기`로 고정했습니다.
- 문제마다 큰 SVG 피자와 `색칠된 조각`, `전체 조각` 수를 함께 보여 줍니다. 색을 보지 못해도 분자와 분모의 근거를 확인할 수 있습니다.
- 정답·오답 뒤 학생이 고른 분수를 계산판에 넣어 `=` 또는 `≠`로 비교합니다. 정답 때는 확인 화면을 충분히 본 뒤 `피자 보기`를 눌러 보상으로 이동합니다.
- 선택지 네 개에는 정답, 분자·분모 뒤바꿈, 색칠하지 않은 조각 세기, 전체를 그대로 분자로 쓰기가 들어갑니다. 오답 문구는 선택 이유에 맞춰 한 줄로 나옵니다.
- 문제 중에는 점수·등급 패널을 숨기고, 문제·조작판·안내·선택지가 Stage 대부분을 쓰게 했습니다.
