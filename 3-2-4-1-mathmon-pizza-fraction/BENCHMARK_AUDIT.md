# 3-2-4-1 기준 차시 비교

## 비교 결과

| 강점 기준 | 1단원 비교 차시 | 4-1 적용 | 판정 |
| --- | --- | --- | --- |
| 수학 판단이 먼저 보임 | 1-2 계산 구조 | 피자에서 색칠된 조각 수와 전체 조각 수를 읽고 분수를 고름 | PASS |
| 그럴듯한 오답 | 1-2 오개념 선택지 | 분자·분모 뒤바꿈, 색칠하지 않은 조각 세기, 전체를 분자로 쓰기를 구분 | PASS |
| 정답 확인 뒤 이동 | 1-4 마지막 확인 | 고른 분수가 피자 계산판에 들어간 뒤 `피자 보기`로 보상 이동 | PASS |
| 진행감과 랜덤 보상 | 1-1 보상 변화, 1-3 진행감 | 문제마다 닫힌 피자 상자를 연 뒤 6종 이벤트 중 하나를 확인 | PASS |
| 다음 목표 | 1-4 결과 흐름 | 결과 6등급과 `다음엔 더 멀리` 흐름 유지 | PASS |

## 입력 통계

정답 경로의 문제당 수학 판단은 1회, 물리 입력은 4탭입니다. 문제 은행 전체에서 동일하므로 수학 판단과 물리 입력의 최소·중앙값·평균·최댓값은 각각 `1/1/1/1회`, `4/4/4/4탭`입니다. 10문제 완주 기준은 수학 판단 10회, 물리 입력 40탭입니다.

## 강제 항목

- 한 화면 한 행동: 피자와 같은 분수 하나 고르기
- 오답 양방향: 색칠 수와 전체 수를 서로 바꾼 경우, 색칠하지 않은 조각을 센 경우
- 마지막 확인: 완성 분수가 계산판 중앙에 남은 뒤 보상 버튼 노출
- 보상: 닫힌 상태와 열린 6종이 서로 다른 512×512 이미지
- 랭킹: UI·API 모두 비활성
