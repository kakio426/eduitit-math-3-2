# 3-2-4-3 기준 차시 비교

## 비교 결과

| 강점 기준 | 1단원 비교 차시 | 4-3 적용 | 판정 |
| --- | --- | --- | --- |
| 수학 관계가 먼저 보임 | 1-2 계산 구조 | 분수 표기와 같은 양의 막대를 한 계산판에서 비교 | PASS |
| 그럴듯한 오답 | 1-2 오개념 선택지 | 진분수·가분수·대분수의 경계와 `분자=분모` 사례를 포함 | PASS |
| 정답 확인 뒤 이동 | 1-4 마지막 확인 | 고른 이름과 관계가 계산판에 들어간 뒤 `상자 보기`로 이동 | PASS |
| 진행감과 랜덤 보상 | 1-1 보상 변화, 1-3 진행감 | 봉인된 분류 상자를 연 뒤 6종 이벤트 중 하나를 확인 | PASS |
| 다음 목표 | 1-4 결과 흐름 | 결과 6등급과 다음 목표 흐름 유지 | PASS |

## 입력 통계

정답 경로의 문제당 수학 판단은 1회, 물리 입력은 4탭입니다. 문제 은행 전체에서 동일하므로 수학 판단과 물리 입력의 최소·중앙값·평균·최댓값은 각각 `1/1/1/1회`, `4/4/4/4탭`입니다. 10문제 완주 기준은 수학 판단 10회, 물리 입력 40탭입니다.

## 강제 항목

- 설명 수학 정확성: `2/3`, `5/4=4/4+1/4`, `1 1/2=2/2+1/2`
- 한 화면 한 행동: 분수 이름 하나 고르기
- 오답 양방향: 가분수와 대분수 혼동, 분자와 분모가 같은 수의 경계 혼동
- 마지막 확인: 분류명과 근거가 같은 작업 영역에 남은 뒤 보상 버튼 노출
- 보상: 닫힌 상태와 열린 6종이 서로 다른 512×512 이미지
- 랭킹: UI·API 모두 비활성
