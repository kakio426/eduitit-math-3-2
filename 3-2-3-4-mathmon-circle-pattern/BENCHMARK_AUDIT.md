# 3-2-3-4 기준 차시 비교 감사

> 2026-08-04 현재 판정: **컴퍼스로 원 그리기 전환 통과**. 아래 2026-07-23 원 무늬 선택 감사는 이전 구현의 비교 기록입니다.

## 현재 버튼 목적

| 버튼 | 누르기 전 학생이 하는 일 | 누른 뒤 보이는 것 |
|---|---|---|
| 원 그리기 | 자 눈금에서 반지름을 직접 맞춤 | 컴퍼스 회전, 선택한 원, 정오 피드백 |
| 무늬 보기 | 정답 원을 확인 | 기존 닫힌 보상 |
| 뽑기 | 보상을 엶 | 기존 보상 변화 |
| 다음 | 보상 변화를 확인 | 다음 문제 또는 기존 결과 화면 |

## 현재 입력 수

- 문제당 수학 입력은 컴퍼스 드래그 1회 이상과 `원 그리기` 1회입니다.
- 오답이면 별도 보기 선택 없이 같은 자에서 바로 고쳐 다시 그립니다.
- 보기 네 개를 읽고 비교하던 입력을 없애고, 성취기준의 핵심 행동인 반지름 설정과 원 그리기를 전면에 놓았습니다.

## 버튼 목적

| 뽑기 | 빛이 얼마나 바뀔지 | 없음, 무작위 결과 열기 | 실제 무늬 빛 변화 |

## 입력 수

- 정답 문제당 수학적 판단 1회, 수학 입력 1회, 전환 입력 3회, 총 4회
- 문제 은행 통계: 최소/중앙값/평균/최대 = **4/4/4/4**
- 한 판: 문제 흐름 40회 + 표지·설명 진입 3회 = **43회**

## 오개념·접근성 증거

- `PATTERN_GAP_CHANGED`, `PATTERN_OFF_LINE`, `PATTERN_SIZE_CHANGED`
- 네 접근성 이름: `같은 크기와 간격`, `간격이 넓음`, `줄에서 벗어남`, `원 크기가 다름`
- 두 화면 크기에서 각 오개념을 실제로 눌러 `05m-p1-pattern-*.png`로 저장했습니다.
