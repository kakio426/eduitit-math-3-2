# 3-2-6-3 기준 차시 비교 감사

검사일: 2026-08-01
최종 판정: **통과**

## 강점별 비교

| 기준 차시 | 가져온 강점 | 현재 증거 |
| --- | --- | --- |
| 1-1 상자런 | 풀이 뒤 직접 여는 보상 | 완성식을 본 뒤 도장 상자 열기 |
| 1-2 로켓발사 | 중심 보상 하나 | `그래프 힘`만 누적 |
| 1-3 점프섬 | 단계별 현재 값 확인 | 큰 도장 식 확인 뒤 작은 도장 단계로 이동 |
| 1-4 로봇 합체 | 두 계산을 합쳐 완성 | `큰 도장×10 + 작은 도장×1 = 전체 수` |

## 강제 계약

한 화면 한 행동, 두 번의 서로 다른 자리값 판단, 자리 바꾸기·±1 오개념, 정답 확인, 마지막 완성식, 겹침 0, Stage-Reveal, 랭킹 비활성 모두 통과했습니다.

## 영역·입력 측정

| 화면 | 1순위 문제판 | 중심 작업판 | 선택지 | 판정 |
| --- | ---: | ---: | ---: | --- |
| 1280×800 | 896.39×465.98 | 896.39×465.98, Stage 폭 74.50% | 최소 210.09×56 | 통과 |
| 1024×768 | 742.22×353.94 | 742.22×353.94, Stage 폭 75.50% | 최소 172.55×52 | 통과 |

- 정보 묶음: 나타낼 수 1, 현재 도장 칸 1, 완성식 1, 선택지 4
- 대기↔완료 경계·중심 차이 0px
- 정답 경로의 문제당 수학 판단 수 min/median/avg/max: `2/2/2/2`
- 정답 경로의 문제당 물리 입력 수 min/median/avg/max: `6/6/6/6`
- 표지·설명 이동을 포함한 한 판 입력: 63회

왼쪽 진행 보상은 Stage 기준 `left 1.65% / top 11% / width 19.2% / height 84%`의 고정 칸을 쓰며, 학습 영역과의 교차는 `0px`입니다. 최종 보상 6등급을 먼저 확정한 뒤 같은 여섯 세계를 잇는 전용 진행 이미지 6장을 만들었고, 결과 이미지 크롭 재사용은 없습니다.

## 버튼 목적

`작은 도장 보기`는 첫 정답을 가리지 않고 확인한 뒤 아직 정하지 않은 일의 자리로 넘어가는 버튼입니다. 보상 버튼은 완성된 수학 관계를 본 뒤 무작위 결과만 엽니다.

## 결론

같은 물건을 반복해서 놓는 자동 풀이가 아니라 학생이 십의 자리와 일의 자리를 직접 결정합니다. 필수 계약 미달과 남은 P0/P1은 없습니다.
