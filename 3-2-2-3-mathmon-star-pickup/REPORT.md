## 1. 게임 개요

`매스몬 별 줍기`는 별을 똑같이 묶고 남는 별을 세면서 `나머지가 있는 나눗셈`을 익히는 에듀잇티 수학 게임입니다. 학생은 처음 수만큼 놓인 별을 보고 몇 묶음까지 만들 수 있는지 고른 뒤, 묶고 남은 별을 직접 판단합니다.

한 문제를 풀 때마다 남은 별이 별병으로 이동하고, `별빛 보기`를 누르면 무작위 별빛 변화가 바로 나타납니다. 10문제를 마치면 처음에 맞힌 문제 수와 누적 별빛을 함께 반영해 여섯 유니콘자리 중 하나가 최종 결과로 나타납니다.

핵심 목표는 학생이 답만 고르는 데서 끝나지 않고 다음 세 관계를 눈으로 확인하게 하는 것입니다.

1. `처음 수`에서 `나누는 수`만큼 몇 묶음을 만들 수 있는지 판단합니다.
2. 몫을 너무 작게 또는 크게 잡았을 때 남거나 모자라는 별을 비교합니다.
3. `나누는 수×몫+나머지=처음 수`의 완성식을 확인합니다.

## 2. 이 게임의 주요 특징

### 실제 별을 묶는 나눗셈

- 오른쪽 계산판에 처음 수만큼 별을 실제 개수로 보여 줍니다.
- 몫을 고르기 전에는 곱과 남은 수를 숨기고 `11 / 12 / 13묶음`처럼 판단에 필요한 보기만 둡니다.
- 학생이 고른 뒤에만 별이 묶음 캡슐로 바뀌고, 곱과 남거나 모자라는 별이 나타납니다.
- 최대 99개의 흩어진 별과 32개의 묶음 캡슐도 고정 계산판 안에 들어갑니다.

### 한 화면에서 한 가지 판단

문제 화면은 왼쪽의 유니콘 별자리판과 오른쪽의 계산판으로 나뉩니다. 현재 단계에서 필요한 지시문과 선택지만 보이고, 전체 풀이 설명이나 다음 단계 선택지는 한꺼번에 펼치지 않습니다.

### 오답 이유가 현재 별로 보임

- 몫이 너무 작으면 남은 별에서 한 묶음을 더 만들 수 있음을 점선 묶음으로 보여 줍니다.
- 몫이 너무 크면 마지막 캡슐의 빈 자리와 모자란 별 수를 보여 줍니다.
- 나머지가 너무 크면 나누는 수만큼 다시 묶을 수 있음을 남은 별 판에서 보여 줍니다.

단순히 `틀렸어요`라고 말하지 않고, 학생이 방금 고른 수가 왜 맞지 않는지 현재 별의 개수와 위치로 확인하게 합니다.

### 정답 확인 뒤 보상 이동

학생이 정답을 고르면 선택지 색만 바뀌지 않습니다. 선택한 몫이 묶음 캡슐과 곱에 반영되고, 나머지는 남은 별 칸에 들어갑니다. 마지막에는 `4×12+2=50` 같은 완성식을 충분히 본 뒤 학생이 `별빛 보기`를 눌러 보상을 확인합니다.

### 왼쪽 별자리가 계속 자라는 보상

왼쪽 `300×656px` 슬롯에는 여섯 단계 유니콘 별자리판이 문제를 푸는 동안 계속 보입니다. 보상이 반영되면 별자리 안의 주요 별이 차례로 켜지고 연결선이 마지막에 한 번 더 밝아집니다. 보상 모달은 오른쪽 계산 영역에 열려 별자리판을 가리지 않습니다.

### 정답은 유리하지만 오답이 무조건 감점은 아님

모든 문제는 같은 랜덤 사건 확률표를 사용합니다. 처음에 맞히면 실제 나머지만큼 별빛을 더 받고, 불리한 사건이 나와도 현재 별빛을 지킵니다. 오답 뒤 다시 맞힌 문제도 `+`, `-`, `별빛 그대로`가 모두 나올 수 있으므로 일부러 운을 기대하며 다시 도전할 여지가 남습니다.

### 다음 결과가 보이는 여섯 단계 보상

최종 화면은 왼쪽의 완성된 유니콘자리와 오른쪽의 결과 묶음으로 나뉩니다. 오른쪽에는 `결과 이름 → 다음 별자리 → 모은 별빛 → 정답 수 → 다시`를 같은 세로 축에 놓았습니다. 최고 단계에서는 `모든 별자리를 밝혔어요!`로 끝을 알려 줍니다.

## 3. 학습 및 게임 규칙

| 항목 | 현재 규칙 |
| --- | --- |
| 문제 수 | 한 판 10문제 |

| 마지막 행동 | 완성식 확인 후 `별빛 보기` |
| 별빛 범위 | 0~100 |
| 최종 결과 조건 | 처음에 맞힌 문제 수와 누적 별빛 동시 반영 |
| 최고 특별 결과 | 초신성 사건과 처음에 맞힌 문제 1개 이상 |
| 전국 순위 | 현재 제품 정책에 따라 비활성화 |

모든 문제는 `처음 수 = 나누는 수×몫+나머지`를 만족하고, 나머지는 항상 `0보다 크고 나누는 수보다 작습니다`.

## 6. 별빛 보상 규칙

모든 문제는 아래 확률표를 똑같이 사용합니다.

| 랜덤 사건 | 확률 | 기본 변화 |
| --- | ---: | ---: |
| 별빛이 늘었어요 | 72% | +4~+8 |
| 별빛이 줄었어요 | 12% | -10~-5 |
| 별빛이 크게 늘었어요 | 10% | +12~+20 |
| 별똥별 | 3% | +6 |
| 별빛 0 | 2.8% | 누적 별빛을 0으로 변경 |
| 초신성 | 0.2% | 특별 결과 |

### 처음에 맞힌 문제

- 실제 나머지 개수만큼 별빛을 먼저 더합니다.
- 구름이나 암흑처럼 불리한 사건이 뽑혀도 별빛이 줄지 않습니다.
- 이때는 `별빛을 지켜 낸 장면`을 보여 주고 나머지 보너스를 유지합니다.
- 초신성 특별 결과를 열 수 있는 자격이 생깁니다.

### 오답 뒤 다시 맞힌 문제

- 같은 확률표를 그대로 사용합니다.
- 나머지 보너스는 받지 않습니다.
- 별빛이 오르거나, 줄거나, 그대로일 수 있습니다.
- 따라서 틀렸다고 무조건 `-`가 되지는 않지만 첫 시도 정답보다 불리합니다.

정답은 분명히 유리하지만 결과를 완전히 결정하지 않으며, 빈손 없이 다시 도전할 운의 여지를 남깁니다.
