# 매스몬 별 줍기

3학년 2학기 2단원 3차시, 나머지가 있는 나눗셈 게임입니다. 동행 매스몬 팩은 `base-pack`, 주인공은 유니콘몬입니다.

## 학습 조작

1. 몫 주변의 세 보기에서 처음 수를 넘지 않는 가장 큰 묶음 수를 고릅니다.
2. 너무 작게 고르면 한 묶음을 더 만들 수 있는 별이 보이고, 너무 크게 고르면 모자란 별이 빨간 칸으로 보입니다.
3. 묶고 남은 밝은 별 수를 한 번에 고릅니다.
4. `나누는 수 × 몫 + 나머지 = 처음 수` 완성식을 확인한 뒤 학생이 `별병 열기`를 누릅니다.

정답 경로의 수학적 판단은 문제마다 2회입니다. 실제 문제 입력도 몫 1회, 나머지 1회로 최소·중앙값·평균·최대가 모두 2회입니다. 화면 이동과 별병 열기는 이 수에서 제외합니다. 같은 답을 만들기 위한 반복 탭은 없습니다.

## 진행과 보상

- 문제 화면 위에는 `1/10`과 함께 현재 별·다음 별의 생성형 제목 이미지가 작게 보입니다.
- 별 등급은 CSS 글자가 아니라 결과 제목 이미지 6장 세트를 재사용합니다.
- 별빛은 하나의 중심 보상이며, 정답이어도 사건은 무작위로 바뀝니다.
- 닫힌 보상은 별병 이미지와 `열기`만, 열린 보상은 사건 이미지·변화량·`다음`만 보여 줍니다.
- 결과 화면의 생성형 `순위 보기` 버튼으로 `전국 별빛 순위`를 엽니다. 점수 이름은 `내 별빛`, 목록 이름은 `별빛 순위`입니다.
- 서버는 `3-2-2-3-mathmon-star-pickup`의 몫·나머지 시도, 나머지 보너스, 보상 사건을 다시 계산해 제출 점수를 검증합니다.
- 오프라인·연결 중·오류·빈 목록·긴 이름 10개와 1~10위 스크롤을 데스크톱·태블릿에서 확인합니다.

| 정답 사건 | 확률 | 별빛 변화 |
|---|---:|---:|
| 별빛이 늘었어요 | 72% | +4~+8 |
| 별빛이 줄었어요 | 12% | -10~-5 |
| 별빛이 크게 늘었어요 | 10% | +12~+20 |
| 별똥별 | 3% | +6 |
| 별빛 0 | 2.8% | 0으로 바뀜 |
| 초신성 | 0.2% | 특별 결과 |

오답이 있었던 문제의 사건은 `별빛이 줄었어요(-18~-8)`로 바뀝니다. 정답을 처음에 맞히면 실제 나머지만큼 별빛이 더해집니다.

| 결과 | 최소 별빛 | 처음에 맞힌 문제 |
|---|---:|---:|
| 별먼지 | 0 | 0 |
| 작은별 | 19 | 2 |
| 별자리 | 35 | 4 |
| 은하 | 53 | 6 |
| 대우주 | 75 | 8 |
| 무지개 초신성 | 특별 사건 | 1 이상 |
