# 매스몬 별 줍기

3학년 2학기 2단원 3차시 `나머지가 있는 나눗셈` 게임입니다. 동행 팩은 `base-pack`, 주인공은 유니콘몬입니다.

## 학생이 하는 일

문제 화면은 왼쪽 유니콘 별자리판과 오른쪽 계산판으로 나뉩니다. 별자리판은 문제를 푸는 동안 계속 보입니다.

1. 처음 수만큼 흩어진 별을 봅니다.
2. `별 47개를 6개씩 묶으면 몇 묶음까지 만들 수 있을까요?`를 생각합니다.
3. 계산 결과가 적히지 않은 `6 / 7 / 8묶음` 보기에서 몫을 고릅니다.
4. 고른 뒤에 별이 묶음 캡슐로 다시 놓입니다.
5. 묶고 남은 별 수를 고릅니다.
6. `6×7+5=47`을 확인하고 `별빛 보기`를 누르면 별빛 점수가 바로 보입니다.

정답 경로의 수학적 판단과 문제 입력은 몫 1회, 나머지 1회로 모두 2회입니다. 같은 답을 만들기 위한 반복 탭은 없습니다.

## 오답과 정답 확인

- 몫이 작으면 남은 별 중 한 묶음 분량을 점선으로 묶어 `한 묶음을 더 만들 수 있어요.`라고 알려 줍니다.
- 몫이 크면 마지막 캡슐의 빈 별자리와 실제 부족 수를 보여 줍니다.
- 몫이 맞으면 묶음 수와 곱, 남은 별 모양을 1.2초 동안 보여 줍니다. 남은 개수는 아직 쓰지 않습니다.
- 나머지 단계에서는 묶음 수에 맞춰 캡슐 크기를 바꾸고 남은 별을 크게 보여 줍니다. `50÷4`의 12묶음은 4열×3행으로 확대합니다.
- 마지막 완성식은 보상 모달이 자동으로 가리지 않습니다.

## 별자리 진행과 보상

처음에 맞힌 문제의 남은 별은 계산판에서 왼쪽 별병으로 이동합니다. 이어서 기존 랜덤 사건이 같은 `별빛`을 바꿉니다. `별빛 보기` 뒤에는 `열기`를 한 번 더 누르지 않고 변화한 점수를 바로 보여 줍니다. 보상 카드는 오른쪽 계산 영역에 열려 왼쪽 별자리를 가리지 않습니다. 별자리 안의 주요 별은 차례로 켜지고, 마지막에는 연결선이 한 번 더 환하게 빛납니다. 별·코인 같은 두 번째 보상은 없습니다.

| 단계 | 결과 이름 | 최소 별빛 | 처음에 맞힌 문제 |
|---:|---|---:|---:|
| 1 | 첫 별 | 0 | 0 |
| 2 | 별무리 | 19 | 2 |
| 3 | 별길 | 35 | 4 |
| 4 | 유니콘자리 | 53 | 6 |
| 5 | 빛나는 유니콘자리 | 75 | 8 |
| 6 | 무지개 유니콘자리 | 특별 사건과 별빛 100 | 1 이상 |

| 랜덤 사건 | 확률 | 기본 변화 |
|---|---:|---:|
| 별빛이 늘었어요 | 72% | +4~+8 |
| 별빛이 줄었어요 | 12% | -10~-5 |
| 별빛이 크게 늘었어요 | 10% | +12~+20 |
| 별똥별 | 3% | +6 |
| 별빛 0 | 2.8% | 0으로 바뀜 |
| 초신성 | 0.2% | 특별 결과 |

모든 문제는 위 확률표를 똑같이 씁니다. 처음에 맞히면 실제 나머지만큼 별빛이 더해지고, 구름이나 암흑이 뽑혀도 별빛은 줄지 않습니다. 이때는 `별빛을 지켜 낸 장면`이 나오고 나머지 보너스만 더해집니다. 오답이 있었던 문제도 같은 표를 다시 뽑으므로 `+`, `-`, `별빛 그대로`가 모두 나올 수 있지만 나머지 보너스는 없습니다. 초신성 특별 결과는 처음에 맞힌 문제가 1개 이상일 때만 열립니다. 사건 확률과 결과 단계 문턱은 바꾸지 않았습니다.

전국 순위 기능은 학생 흐름과 네트워크 요청에서 꺼져 있습니다.
