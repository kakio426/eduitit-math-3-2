# 매스몬 별 줍기

3학년 2학기 2단원 3차시 `나머지가 있는 나눗셈` 게임입니다. 동행 팩은 `base-pack`, 주인공은 유니콘몬입니다.

## 학생이 하는 일

문제 화면은 왼쪽 유니콘 별자리판과 오른쪽 계산판으로 나뉩니다. 별자리판은 문제를 푸는 동안 계속 보입니다.

1. 처음 수만큼 흩어진 별을 봅니다.
2. `6×몇이 47을 넘지 않을까요?`처럼 곱을 비교합니다.
3. `6×7=42 / 7묶음` 형식의 보기에서 몫을 고릅니다.
4. 고른 뒤에 별이 묶음 캡슐로 다시 놓입니다.
5. 묶고 남은 별 수를 고릅니다.
6. `6×7+5=47`을 확인하고 `별병 열기`를 누릅니다.

정답 경로의 수학적 판단과 문제 입력은 몫 1회, 나머지 1회로 모두 2회입니다. 같은 답을 만들기 위한 반복 탭은 없습니다.

## 오답과 정답 확인

- 몫이 작으면 남은 별 중 한 묶음 분량을 점선으로 묶어 `한 묶음을 더 만들 수 있어요.`라고 알려 줍니다.
- 몫이 크면 마지막 캡슐의 빈 별자리와 실제 부족 수를 보여 줍니다.
- 몫이 맞으면 묶음 수와 곱, 남은 별을 1.2초 동안 보여 준 뒤 나머지 단계로 갑니다.
- 나머지 단계에서는 묶음 캡슐을 작게 접고 남은 별을 크게 보여 줍니다.
- 마지막 완성식은 보상 모달이 자동으로 가리지 않습니다.

## 별자리 진행과 보상

처음에 맞힌 문제의 남은 별은 계산판에서 왼쪽 별병으로 이동합니다. 이어서 기존 랜덤 사건이 같은 `별빛`을 늘리거나 줄입니다. 별·코인 같은 두 번째 보상은 없습니다.

| 단계 | 결과 이름 | 최소 별빛 | 처음에 맞힌 문제 |
|---:|---|---:|---:|
| 1 | 첫 별 | 0 | 0 |
| 2 | 별무리 | 19 | 2 |
| 3 | 별길 | 35 | 4 |
| 4 | 유니콘자리 | 53 | 6 |
| 5 | 빛나는 유니콘자리 | 75 | 8 |
| 6 | 무지개 유니콘자리 | 특별 사건과 별빛 100 | 1 이상 |

| 정답 사건 | 확률 | 별빛 변화 |
|---|---:|---:|
| 별빛이 늘었어요 | 72% | +4~+8 |
| 별빛이 줄었어요 | 12% | -10~-5 |
| 별빛이 크게 늘었어요 | 10% | +12~+20 |
| 별똥별 | 3% | +6 |
| 별빛 0 | 2.8% | 0으로 바뀜 |
| 초신성 | 0.2% | 특별 결과 |

처음에 맞히면 실제 나머지만큼 별빛이 더해집니다. 오답이 있었던 문제는 `별빛이 줄었어요(-18~-8)` 사건으로 바뀝니다. 확률과 문턱은 재설계 전 값에서 바꾸지 않았습니다.

기존 `전국 별빛 순위`와 서버 점수 검증은 유지했습니다. 이번 재설계에서 새 순위 기능은 추가하지 않았습니다.
