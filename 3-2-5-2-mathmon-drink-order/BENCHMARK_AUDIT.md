# 3-2-5-2 기준 차시 비교 점검

점검일: 2026-07-28  
비교군: 3학년 2학기 1단원 1~4차시

| 항목 | 판정 | 근거 |
| --- | --- | --- |
| 수학적 판단 | ✅ | mL 계산, 1000mL를 1L로 바꾸기, 전체 들이 판단이 이어집니다. |
| 한 화면 한 행동 | ✅ | 단계마다 현재 값 하나만 골라 다음 계산판 칸을 채웁니다. |
| 그럴듯한 오답 | ✅ | 받아올림·받아내림 누락과 주문량 비교 오류가 포함됩니다. |
| 정답 확인 | ✅ | 각 값이 계산판에 들어가고 완성 들이를 본 뒤 보상을 엽니다. |
| 보상 공개 | ✅ | 닫힌 주문 컵 → 사건 이미지 → 다음 문제 순서입니다. |
| 결과 정보 | ✅ | 결과 이름·가게 인기·바로 맞힌 수·다음 목표가 한 축에 있습니다. |
| 텍스트/겹침 | ✅ | 1280×800, 1024×768 주요 상태에서 교차 0건입니다. |
| 랭킹 비활성화 | ✅ | 학생 흐름과 네트워크 요청에 랭킹이 없습니다. |

정답 경로의 수학 판단 입력은 문제당 최소 `1`, 중앙값 `3`, 평균 `2.4`, 최대 `3`회입니다. 보상 열기와 다음을 포함한 물리 입력은 최소 `3`, 중앙값 `5`, 평균 `4.4`, 최대 `5`회입니다. 늘어난 입력마다 mL 계산, 단위 바꾸기, 전체 들이라는 새 판단이 있습니다.

P0/P1/P2 수정 항목은 모두 닫혔습니다.
