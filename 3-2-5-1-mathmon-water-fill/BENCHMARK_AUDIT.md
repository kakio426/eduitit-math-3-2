# 3-2-5-1 기준 차시 비교 점검

점검일: 2026-07-28  
비교군: 3학년 2학기 1단원 1~4차시

| 항목 | 판정 | 근거 |
| --- | --- | --- |
| 수학적 판단 | ✅ | 눈금 읽기와 두 물통 비교를 학생이 직접 고릅니다. |
| 한 화면 한 행동 | ✅ | 문제당 현재 들이 선택 하나만 크게 보입니다. |
| 그럴듯한 오답 | ✅ | 100mL·1L 차이, 반대 물통, 같음, 알 수 없음으로 구성합니다. |
| 정답 확인 | ✅ | 고른 값이 계산판에 들어간 뒤 `물통 보기`가 열립니다. |
| 보상 공개 | ✅ | 닫힌 캡슐 → 사건 이미지 → 다음 문제 순서입니다. |
| 결과 정보 | ✅ | 결과 이름·물통 힘·바로 맞힌 수·다음 목표가 한 축에 있습니다. |
| 텍스트/겹침 | ✅ | 1280×800, 1024×768 주요 상태에서 교차 0건입니다. |
| 랭킹 비활성화 | ✅ | 학생 흐름과 네트워크 요청에 랭킹이 없습니다. |

정답 경로의 수학 판단 입력은 문제당 최소·중앙값·평균·최대 모두 `1`회입니다. 보상 열기와 다음을 포함한 물리 입력은 문제당 `3`회입니다. 반복 입력은 보상 사건 확인과 다음 문제 이동이며, 수학 답을 다시 입력시키지 않습니다.

P0/P1/P2 수정 항목은 모두 닫혔습니다.
