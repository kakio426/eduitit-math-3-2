## Humanizer 학생 문구 QA

- `70에서 십의 자리 몫과 남은 수를 골라요.`처럼 학생이 평소 쓰는 수로 말합니다.
- 첫 단계 선택지는 십의 자리 숫자 `2`, `1`만 쓰지 않고 `몫 20`, `남은 수 10`처럼 실제 값을 보여 줍니다.
- `남은 10과 일의 자리 6을 합친 수를 골라요.`처럼 실제로 누를 값을 정확히 말합니다.
- 숫자 뒤 조사는 마지막 숫자에 맞춰 `15를`, `16을`처럼 자동으로 바꿉니다. 화면 설명과 읽어 주기 문구에서 `15을` 같은 표현이 나오지 않습니다.
- 설명 화면은 `1이 남아요.`, `6을 내려 16을 만들어요.`처럼 한 문장에 한 행동만 담고, 계산식은 `7÷2=3`, `16÷2=8`로 짧게 분리했습니다.
- `10 ÷ 2의 몫을 골라요.`처럼 내린 수와 나누는 수를 함께 보여 줍니다.
- 숫자에 따라 조사가 어색해지던 확인 문구는 `남은 십 1 · 일의 자리 0 → 10` 구조로 바꿨습니다.
- 오답 피드백에 남아 있던 `2십`, `…십이라` 같은 표현도 `20`, `곱하면 40이라 30보다 커요.`처럼 실제 수로 짧게 바꿨습니다.
- 닫힌 보상은 안내 문장을 화면에서 숨겨 이미지와 `열기` 버튼만 보이게 했습니다.
- `핵심`, `이벤트`, `등급`, `게이트` 같은 제작자 말과 숫자+`십` 표기가 학생 화면 동적 문구에 0건임을 다시 검색했습니다.
