## 3. 화면별 확인

### 표지·설명

- [x] 생성형 배경·제목·시작 버튼이 모두 보인다.
- [x] 데스크톱과 태블릿에서 시작 버튼 글자·플레이 아이콘이 비지 않는다.
- [x] 설명 1은 큰 보기에서 `나누는 수×몫`과 `나머지`를 고르는 현재 조작을 보여 주고, 설명 2는 10문제 뒤 금고 목표를 맡는다.
- [x] 설정 모달에 배경 소리·효과 소리·방법 다시 보기·처음부터·닫기가 있다.

### 검산 관계 만들기

- [x] 학생이 정답 1개와 대표 오개념 3개 가운데 먼저 곱할 두 수를 고른다.
- [x] `처음 수×나누는 수`는 처음 수가 마지막 비교에 쓰임을, 나머지를 곱한 선택은 나머지가 더할 수임을 한 줄로 알려 준다.
- [x] 오답 관계가 현재 계산판의 `?×?` 자리에 들어간다.
- [x] 다음 단계에서 더할 `나머지`를 역할 보기 4개 가운데 고른다.
- [x] 나머지 대신 나누는 수·처음 수·몫을 다시 고르는 오답이 문제 은행에 있다.

### 자동 비교하고 틀린 곳 찾기

- [x] 더할 수를 고르면 시스템이 합을 계산하고 별도 버튼 없이 `=` 또는 `≠`를 보여 준다.
- [x] 맞지 않는 식은 `몫 / 나머지` 중 다른 곳을 찾는다.
- [x] 맞는 식과 맞지 않는 식이 한 판에 모두 포함된다.
- [x] 마지막 확인에서 완성된 검산식과 처음 수의 같고 다름이 보인다.
- [x] 학생이 확인한 뒤에만 금고 보상을 연다.
- [x] 각 단계의 대기·정답 확인에서 실제 SVG 계산판 표면과 지시문·선택지가 서로 덮이지 않는다.

### 보상·결과

- [x] 닫힌 보상은 금고 이미지와 `열기` 버튼만 보인다.
- [x] 열린 보상은 사건 이미지·변화량·노란 `다음` 버튼만 보인다.
- [x] `열어 봐요`와 `열기`처럼 같은 행동을 반복하지 않는다.
- [x] 결과 장면·6단계 제목 이미지·정답 수·열쇠 힘·생성형 다시 버튼이 연결된다.
- [x] 문제 중 왼쪽 보상판이 현재 금고 그림·이름과 다음 금고를 이어 보여 준다.
- [x] 특별 결과의 다음 목표가 낮은 단계로 돌아가지 않는다.

## 4. 판단 수와 입력 수

500개 시드, 5,000문제를 현재 모델에서 생성해 정답 경로를 계산했다.

| 항목 | 최소 | 중앙값 | 평균 | 최대 |
|---|---:|---:|---:|---:|
| 수학적 판단 | 2 | 2 | 2.4 | 3 |
| 선택 입력 | 2 | 2 | 2.4 | 3 |

맞는 식은 곱할 두 수와 더할 수의 두 판단, 틀린 식은 다른 곳 찾기까지 세 판단이다. 곱·합과 같고 다름은 고른 관계로 정해지므로 별도 입력을 두지 않는다. 숫자 자릿수와 상관없이 판단 1회당 선택 1회이며, 같은 뜻의 판단을 되풀이하지 않는다.

## 5. Humanizer 학생 문구 QA

| 문구 | 판정 | 이유 |
|---|---:|---|

## 8. 제품 선택

- 전국 순위: **범위 밖**. 현재 제품 정책에 따라 랭킹 문구·버튼·화면·네트워크 요청을 노출하지 않으며 `scoreboard.enabled=false`를 유지한다.
- 문제 중 `현재 금고 → 다음 금고`: **완료**. 왼쪽 보상판에 현재 그림·이름과 다음 이름이 연결되고, 최고 단계에서는 `최고 금고예요`로 끝난다.

P0·P1은 남지 않았다. 예전 `09-scoreboard-*.png`는 현재 실행 증거로 사용하지 않는다.
