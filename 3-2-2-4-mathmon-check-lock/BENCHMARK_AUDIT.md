## 1. 기준 차시별 비교

| 기준 차시 | 가져온 강점 | 검산 자물쇠 반영 | 판정 |
|---|---|---|---:|
| 1-1 상자런 | 계산 뒤 랜덤 손익과 재도전 기대 | 매 문제 금고를 열어 열쇠 힘 증가·감소·0·희귀 사건을 확인 | 통과 |
| 1-2 로켓발사 | 계산 단계가 최종 결과로 이어짐 | 곱하기 → 나머지 더하기 → 자동 `=`·`≠` → 틀린 식만 다른 곳 찾기로 연결 | 통과 |
| 1-3 점프섬 | 문제 진행과 마지막 도착점 | `1/10`~`10/10`, 열쇠 힘, 6단계 금고 결과 유지 | 일부 통과 |
| 1-4 로봇 합체 | 현재 단계 중심 조작과 값 반영 | 숫자판 한 행동, 계산판 반영, 필요할 때만 두 선택지, 마지막 검산식 뒤 학생이 금고를 엶 | 통과 |

1단원 화면을 통째로 복제하지 않았다. 검산이라는 차시 목표에 맞게 학생이 곱한 값과 더한 값을 직접 만들고, 틀린 식에서는 달라진 곳을 찾는 흐름을 보존했다. 같고 다름은 입력한 값으로 이미 결정되므로 학생에게 다시 묻지 않는다.

## 3. 화면별 확인

### 표지·설명

- [x] 생성형 배경·제목·시작 버튼이 모두 보인다.
- [x] 데스크톱과 태블릿에서 시작 버튼 글자·플레이 아이콘이 비지 않는다.
- [x] 설명 1은 곱하고 나머지를 더하는 방법, 설명 2는 10문제 뒤 금고 목표를 맡는다.
- [x] 설정 모달에 배경 소리·효과 소리·방법 다시 보기·처음부터·닫기가 있다.

### 곱하고 더하기

- [x] 학생이 곱한 값을 숫자판에 직접 넣는다.
- [x] 너무 큰 값은 `곱한 값이 너무 커요.`, 너무 작은 값은 `곱한 값이 너무 작아요.`로 구분한다.
- [x] 오답값이 현재 계산판의 곱한 값 칸에 들어간다.
- [x] 다음 단계에서 나머지를 더한 값을 다시 숫자판에 넣는다.
- [x] 나머지를 빼먹거나 나누는 수를 더하는 오답이 문제 은행에 있다.

### 자동 비교하고 틀린 곳 찾기

- [x] 더한 값이 들어가면 별도 버튼 없이 `=` 또는 `≠`가 보인다.
- [x] 맞지 않는 식은 `몫 / 나머지` 중 다른 곳을 찾는다.
- [x] 맞는 식과 맞지 않는 식이 한 판에 모두 포함된다.
- [x] 마지막 확인에서 곱하고 더한 값과 처음 수의 같고 다름이 보인다.
- [x] 학생이 확인한 뒤에만 금고 보상을 연다.
- [x] 각 단계의 대기·정답 확인에서 실제 SVG 계산판 표면과 지시문·선택지가 서로 덮이지 않는다.

### 보상·결과

- [x] 닫힌 보상은 금고 이미지와 `열기` 버튼만 보인다.
- [x] 열린 보상은 사건 이미지·변화량·노란 `다음` 버튼만 보인다.
- [x] `열어 봐요`와 `열기`처럼 같은 행동을 반복하지 않는다.
- [x] 결과 장면·6단계 제목 이미지·정답 수·열쇠 힘·생성형 다시 버튼이 연결된다.
- [x] 특별 결과의 다음 목표가 낮은 단계로 돌아가지 않는다.

## 4. 판단 수와 입력 수

500개 시드, 5,000문제를 현재 모델에서 생성해 정답 경로를 계산했다.

| 항목 | 최소 | 중앙값 | 평균 | 최대 |
|---|---:|---:|---:|---:|
| 수학적 판단 | 2 | 2 | 2.4 | 3 |
| 숫자·선택 입력 | 6 | 6 | 6.413 | 9 |

맞는 식은 곱한 값과 더한 값의 두 판단, 틀린 식은 다른 곳 찾기까지 세 판단이다. 같고 다름은 더한 값으로 정해지므로 별도 입력을 두지 않는다. 숫자 자릿수가 늘어날 때만 탭 수가 늘며, 같은 뜻의 판단을 되풀이하지 않는다.

## 5. Humanizer 학생 문구 QA

| 문구 | 판정 | 이유 |
|---|---:|---|
| `곱한 값을 숫자판에 넣어요.` | 통과 | 현재 행동 하나가 바로 보임 |
| `더한 값을 숫자판에 넣어요.` | 통과 | 앞 단계와 행동이 분리됨 |
| `몫 또는 나머지를 눌러요.` | 통과 | 틀린 곳 찾기 행동만 말함 |
| `곱하고 더한 값` | 통과 | 어른말 `검산값` 대신 화면에서 한 행동을 그대로 말함 |
| `곱한 값이 너무 커요.` | 통과 | 오답 방향을 초3 말로 바로 설명 |
| `열쇠 힘은 얼마나 나올까요?` | 통과 | 버튼 행동어를 되풀이하지 않음 |

학생 화면에 `핵심`, `메커니즘`, `게이트`, `토큰`, `오브젝트`, `부분곱` 같은 제작자 말을 쓰지 않는다.
