## 2026-07-14 자동 비교·시각 우선순위 수정

- 곱한 값과 더한 값을 입력하면 같고 다름은 수학적으로 이미 결정됩니다. 새 판단이 없던 `같아요 / 달라요` 입력을 삭제하고 계산판이 `=` 또는 `≠`를 자동으로 보여 주도록 바꿨습니다.
- 맞는 식은 곱하기·더하기 두 판단 뒤 완성식으로 이동합니다. 틀린 식은 자동 `≠` 확인 뒤에만 `몫 / 나머지` 가운데 다른 곳을 찾습니다.
- 마지막 `자물쇠 열기`는 무작위 열쇠 힘을 공개하므로 누르기 전후 정보가 달라집니다. 이 버튼은 계산 버튼이 아니라 계산과 보상을 잇는 선택으로 유지했습니다.
- 좁던 검산 계산판을 가로형으로 다시 짜고, 문제 작업 영역을 Stage 너비의 76~84%, 핵심 계산판을 73.27~80.98%로 키웠습니다.
- 완료 상태에서도 계산판과 `완성식 + 자물쇠 열기` 상자를 같은 1열·같은 중앙 축으로 고정했습니다. 현재 Codex 패널에서 중심 차이 0px, 겹침 0px입니다.
- 현재 Codex 패널 `931×897`, DPR 2를 `codex-live-panel-regression`으로 추가했습니다. 실제 Stage는 `893.78×558.61`이며 핵심 계산판 너비는 Stage의 80.78%입니다.
- 설명 1 이미지는 `곱한 값을 넣어요 → 나머지를 더해요 → 처음 수와 같은지 봐요` 흐름으로 다시 만들었습니다. 세 번째 장면은 학생이 누르는 레버 없이 자동 결과만 보여 줍니다.
