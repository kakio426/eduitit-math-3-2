# 3-2-6-2 기준 차시 비교 감사

검사일: 2026-07-23
최종 판정: **통과**

## 강점별 비교

| 기준 차시 | 가져온 강점 | 현재 증거 |
| --- | --- | --- |
| 1-1 상자런 | 풀이 뒤 직접 여는 보상 | 전체 식 확인 뒤 해독 상자 열기 |
| 1-2 로켓발사 | 중심 보상 하나 | `해독 힘`만 누적 |
| 1-3 점프섬 | 관계를 그림으로 확인 | 모든 그림의 단위가 합쳐져 곱셈식 완성 |
| 1-4 로봇 합체 | 오답·정답 상태 분리 | 단위 누락과 ±한 단위 식을 작업판에 표시 |

## 강제 계약

한 화면 한 행동, 단위에 대한 수학적 판단, 대표 오개념, 정답 확인 뒤 보상, 겹침 0, 첫 결과, 랜덤 보상, 랭킹 비활성 모두 통과했습니다.

## 영역·입력 측정

| 화면 | 1순위 문제판 | 중심 작업판 | 선택지 | 판정 |
| --- | ---: | ---: | ---: | --- |
| 1280×800 | 1159.19×457.98, 면적 58.68% | 1040×384.05, 폭 86.44% | 최소 275.80×56 | 통과 |
| 1024×768 | 942.13×343.47, 면적 53.57% | 916.13×288.86, 폭 93.19% | 최소 222.53×52 | 통과 |

- 정보 묶음: 단위 열쇠 1, 그림 묶음 1, 식 1, 선택지 4
- 대기↔완료 경계·중심 차이 0px
- 문제당 입력 4회, 한 판 43회

## 결론

그림 수만 세는 추측으로 통과할 수 없고 `그림 하나의 값 × 그림 수`를 판단해야 합니다. 필수 계약 미달과 남은 P0/P1은 없습니다.
