# 소셜몬 6학년 발견 친구 팩 V1 디자인 계약

## 목적

6학년 여러 사회 단원에서 공용 후보 풀로 돌려 쓸 소셜몬 6종이다. 기존 3학년
승인 팩과 4·5학년 준비 팩, 수학 매스몬의 활성·보존 후보까지 대조해 종과
주요 실루엣을 반복하지 않는다. 화풍과 파일 규격은
`socialmon-v1-anime-sticker`를 유지한다.

## 세트 계약

- 수량: 6종, 전체 번호 `19~24`
- 생성 원본: 평평한 `#00ff00` 크로마키 배경의 정사각 PNG. 민트색 몸을
  쓰는 애벌레몬만 가장자리 보존을 위해 `#ff00ff`를 쓴다.
- 투명 원본: `768×768` PNG, 알파 포함
- 실행본: `768×768` WebP, 알파 포함, quality 86
- 화면 비율: 정면 또는 3/4 정면의 단독 전신
- 채움 비율: 투명 캔버스의 `70~82%`
- 공통 화풍: 밝고 선명한 고광택 2D 게임 스티커, 따뜻한 짙은 갈색 또는
  대표색 외곽선, 부드러운 내부 명암, 작은 카드에서도 읽히는 얼굴과 윤곽
- 성격 분포: 든든함·신중함·호기심·낙천성·리더십·성장을 고르게 배치
- 공통 금지: 글자, 로고, 배경 장면, 바닥 그림자, 큰 소품, 실사, 3D,
  수채화, 금속 로봇, 무기, 공포 표현, 문화 집단을 떠올리게 하는 고정 복식
- 실행 상태: 사용자 시각 승인 전 `draft-style-review`

## 생성 프롬프트

모든 캐릭터는 4학년 팩의 `DESIGN_BRIEF.md`에 적힌 공통 생성 프롬프트를
그대로 사용하고, `Primary request`, `Personality`만 이 표의 종·실루엣·성격에
맞게 바꾼다. 이미지 1은 기존 승인 소셜몬, 이미지 2는 수학 기본팩의 화풍
참조이며, 두 이미지의 종·자세·무늬·소품은 복제하지 않는다. 애벌레몬은
몸의 민트색과 분리되는 `#ff00ff` 배경을 쓴다.

## 승인 게이트

1. 6종의 전신과 고유 실루엣이 작은 결과 카드에서도 바로 구분된다.
2. 기존 3학년 팩, 4·5학년 준비 팩, 수학 매스몬 활성·보존 후보와 겹치지 않는다.
3. 선 두께, 내부 명암, 얼굴 밀도, 카메라 거리, 채움 비율이 기존 승인
   소셜몬과 같은 계열이다.
4. 강한 캐릭터도 무섭거나 공격적으로 보이지 않고, 여섯 성격이 표정과 자세로
   서로 구분된다.
5. 투명 PNG와 WebP의 네 모서리가 투명하고 녹색 테두리가 없다.
6. 사용자 시각 승인 전에는 정식 차시 런타임에 연결하지 않는다.
