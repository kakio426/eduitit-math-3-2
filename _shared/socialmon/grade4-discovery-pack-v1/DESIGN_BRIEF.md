# 소셜몬 4학년 발견 친구 팩 V1 디자인 계약

## 목적

기존 3학년용 `socialmon-discovery-pack-v1` 6종 뒤에 이어지는 4학년 공용
소셜몬 6종이다. 한 차시 전용 캐릭터를 만들지 않고 4학년 여러 단원에서 후보
풀로 돌려 쓴다. 수학 매스몬 기본팩과 기존 소셜몬의 밝은 2D 애니 스티커
화풍은 잇되 동물종과 주요 실루엣은 반복하지 않는다.

## 세트 계약

- 수량: 6종, 전체 번호 `07~12`
- 생성 원본: 평평한 `#00ff00` 크로마키 배경의 정사각 PNG
- 투명 원본: `768×768` PNG, 알파 포함
- 실행본: `768×768` WebP, 알파 포함, quality 86
- 화면 비율: 정면 또는 3/4 정면의 단독 전신
- 채움 비율: 투명 캔버스의 `70~82%`
- 공통 화풍: `socialmon-v1-anime-sticker`, 밝고 선명한 고광택 2D 게임
  스티커, 따뜻한 짙은 갈색 또는 캐릭터 대표색 외곽선, 부드러운 내부 명암
- 성격 분포: 다정함·활기·차분함·협동·씩씩함·끈기를 고르게 배치
- 공통 금지: 글자, 로고, 배경 장면, 바닥 그림자, 큰 가방·지도·도구,
  실사, 3D 장난감, 수채화, 금속 로봇, 무기, 공포 표현, 문화 집단을
  떠올리게 하는 고정 복식
- 실행 상태: 사용자 시각 승인 전 `draft-style-review`

## 공통 생성 프롬프트

```text
게임 캐릭터 아이콘, 한국 초등 사회 퀴즈용 소셜몬 단독 컷.
Scene: <종·고유 실루엣·행동 자세>를 가진 오리지널 소셜몬 한 마리가 정사각 캔버스 중앙에 선다. 승인 소셜몬 시트는 직접 화풍 기준, 수학 기본팩은 선과 명암의 보조 기준으로만 사용하며 새 종·새 자세·새 무늬를 설계한다. 배경은 제거용 단색 크로마키 #00FF00 하나로 캔버스 끝까지 균일하게 채운다. 캐릭터에는 <대표색 2~3색>을 사용한다.
Camera: 정면에 가까운 3/4 시점, 단독 전신, 정사각 아이콘의 70~82% 채움, 머리부터 발·지느러미·더듬이·꼬리 끝까지 보이는 넉넉한 여백.
Lighting: 캐릭터 안쪽에 부드러운 셀 명암과 작은 고광택 하이라이트, 배경은 밝기 변화가 없는 평면광.
Color grading: 따뜻한 외곽선 #4B2A1F, 밝은 하이라이트 #FFF4D6, 제거용 배경 #00FF00, 캐릭터 대표색은 종마다 명확하게 분리.
Texture/Medium: 밝고 선명한 2D 애니 게임 스티커, 깨끗한 컬러 외곽선, 부드러운 셀 쉐이딩, 초등학생이 즉시 읽는 표정, 브랜드와 글자 영역이 비어 있는 클린 마감.
Output: 한 마리의 생물형 본체와 작은 카드에서도 구분되는 독립 실루엣. 성격은 <성격>이며 표정·눈·입·몸 자세로 드러난다. AR 1:1
```

## 승인 게이트

1. 6종의 전신과 종 고유 실루엣이 작은 결과 카드에서도 바로 구분된다.
2. 기존 3학년 소셜몬 6종과 수학 매스몬 활성·보존 후보의 종 및 주요
   실루엣이 겹치지 않는다.
3. 선 두께, 내부 명암, 머리·몸 비율, 카메라 거리와 채움 비율이 기존
   소셜몬 팩과 같은 계열이다.
4. 6종이 같은 큰 눈·같은 미소·같은 둥근 몸으로 반복되지 않는다.
5. 투명 PNG와 WebP의 네 모서리가 투명하고 녹색 테두리가 없다.
6. 사용자 시각 승인 전에는 정식 차시 런타임에 연결하지 않는다.
