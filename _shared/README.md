# 공용 자산

여러 차시에서 재사용할 로고, 캐릭터, 보상 이미지, 디자인 메모를 둡니다.

- `brand/`: 에듀잇티 로고, 공용 배지, 색상 메모
- `mathmon/`: 여러 게임에서 재사용할 수 있는 매스몬 원본 또는 변형
- `action-buttons/`: 설명·보상 흐름에서 반복하는 공용 생성형 주요 행동 버튼
- `result-count/`: 결과 정답 수 `0/10`~`10/10` 공용 생성 이미지 세트
- `result-actions/`: 결과 화면에서 반복하는 공용 생성 버튼 아트
- `scoreboard/`: 공용 순위 화면과 `순위 보기` 버튼

공용 선택 자산의 실행 참조 규칙은 [COMMON_RESOURCE_CONTRACT.md](COMMON_RESOURCE_CONTRACT.md)에 정리합니다.

차시별로만 쓰는 이미지는 각 차시 폴더 안에 둡니다.
