## 버튼 목적

| 버튼 | 누르기 전 모르는 것 | 수학적 판단 | 누른 뒤 보이는 것 |
|---|---|---|---|
| 컴퍼스 선택지 | 반지름과 같은 벌림 | 길이 관계 1회 | 다른 크기의 원호 또는 중심·벌림·회전·완성 원 |
| 마법 보기(완료) | 이번 랜덤 보상 | 없음, 완성 원 확인 뒤 전환 | 닫힌 마법 상자 |
| 마법 보기(보상) | 빛이 얼마나 바뀔지 | 없음, 무작위 결과 열기 | 실제 마법진 빛 변화와 현재 단계 |
| 다음 | 다음 문제 | 없음, 확인 뒤 전환 | 다음 문제 또는 최종 결과 |

## 입력 수

- 정답 문제당 수학적 판단 1회, 수학 입력 1회, 전환 입력 3회, 총 4회
- 문제 은행 통계: 최소/중앙값/평균/최대 = **4/4/4/4**
- 한 판: 문제 흐름 40회 + 표지·설명 진입 3회 = **43회**

## 오개념 증거

- `COMPASS_TOO_NARROW`
- `COMPASS_TOO_WIDE`
- `COMPASS_USES_DIAMETER`
- 두 화면 크기에서 각 오개념을 실제로 눌러 `05m-p1-compass-*.png`로 저장했습니다.
