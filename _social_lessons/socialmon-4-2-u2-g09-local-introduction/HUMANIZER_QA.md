# Humanizer 학생 문구 QA

검토 기준은 `/Users/yubyeongju/.agents/skills/humanizer/SKILL.md`의 의미 보존, 번역투 줄이기, 4학년 학생이 소리 내어 읽기 쉬운 문장이다.

| 영역 | 확인한 문구 | 판정·수정 |
|---|---|---|
| 표지 목표 | `알릴 내용과 소개 방법을 알맞게 이어 봐요.` | 교사용 표현인 `매체의 특성` 대신 학생이 화면에서 하는 판단을 씀 |
| 방법 안내 | `자료를 크게 살펴봐요.`, `답을 골라 확인해요.`, `흔적이 모이면 소셜몬이 보여요.` | 한 문장에 행동 하나, 소리 내어 읽기 쉬움 |
| 자료 문항 | `자료를 보고 하나 골라요.`, `소식지를 보고 하나 골라요.` | 화면에서 바로 할 행동만 남김 |
| 관계 문항 | `왼쪽을 누른 뒤 알맞은 오른쪽을 눌러요.` | 필수 드래그 없이 탭 순서를 분명히 말함 |
| 순서 문항 | `먼저 할 일부터 차례로 눌러요.` | 짧고 한 번에 읽힘 |
| 자료 설명 | `누리집 화면에 사진과 소개 글이 함께 있어요.` | 정답을 미리 말하지 않고 보이는 모습만 말함 |
| 상황 문항 | `공식 누리집에서 확인한 사실을 쓰고, 어디서 알았는지 적어요.` | `출처 표기`를 학생이 바로 이해할 수 있는 말로 풀어 씀 |
| 결과 | `자료를 살펴 알릴 내용을 찾고, 소개 방법을 알맞게 이어 보았어요.` | 학생이 한 일을 짧게 되짚음 |

`매체`, `저작권`, `콘텐츠 구성`, `사실 검증`처럼 어른에게 편한 표현은 학생 화면에서 각각 `소개 자료`, `허락 없이 사진을 쓰지 않기`, `자료를 만들어요`, `사실을 확인해요`로 바꿨다. `핵심`, `생산량`, `출하`, `측정`, `등급`, `적용`, `이벤트`, `토큰`, `오브젝트`, `게이트`, `힘`은 학생 화면 문구와 접근성 문구에 쓰지 않았다. 문항 지시·선택지·피드백·결과 문장은 한 문장에 행동 하나가 중심이 되도록 확인했다.
