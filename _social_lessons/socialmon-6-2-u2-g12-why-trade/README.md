# 소셜몬 무역이 필요한 까닭

6학년 2학기 사회 2단원 13~14차시에서 무역의 뜻과 필요성을 확인하는 6문제 퀴즈입니다.
수입·수출을 구분하고, 나라별 자원·기술 차이 때문에 물자와 서비스를 주고받는 까닭을
사례로 생각합니다.

고르기·이어 보기·나누어 보기 세 조작을 탭으로 사용합니다. 백란도 교역 그림과 무역 놀이
자료를 살펴보며, 자료 그림과 선택지 그림은 각각 교과 근거와 뜻을 돕는 장식으로
구분했습니다.

```bash
node scripts/build-social-quiz.mjs socialmon-6-2-u2-g12-why-trade
node scripts/check-social-quiz.mjs socialmon-6-2-u2-g12-why-trade
```

자료 출처와 사용 범위는 `SOURCE_LEDGER.md`, 설계는 `PLAN.md`, 최신 실행 검증은
`REPORT.md`에서 확인합니다.
