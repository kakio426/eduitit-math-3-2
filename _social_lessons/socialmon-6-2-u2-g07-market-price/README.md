# 소셜몬 시장 가격 탐정

6학년 2학기 사회 2단원 1~2차시를 다루는 6문제 소셜몬 퀴즈입니다. 시장에서 사려는
사람 수와 물건의 양에 따라 가격이 달라질 수 있고, 가계와 기업이 선택하며 경쟁한다는
관계를 자료와 사례로 확인합니다.

학생 흐름은 `cover → tutorial → play → result` 네 화면입니다. 문제는 고르기와 나누어
보기 두 조작이며 모두 탭으로 풀 수 있습니다. 지도서 자료 두 장과 네 장의 선택지
그림을 사용하고, 선택지 그림은 정답 근거가 아닌 뜻을 돕는 장식입니다.

```bash
node scripts/build-social-quiz.mjs socialmon-6-2-u2-g07-market-price
node scripts/check-social-quiz.mjs socialmon-6-2-u2-g07-market-price
```

출처와 사용 범위는 `SOURCE_LEDGER.md`, 설계 판단은 `PLAN.md`, 현재 실행 검증은
`REPORT.md`에서 확인합니다.
