# Humanizer 학생 문구 의미 보존 감사

검토일: 2026-08-12
대상: 4학년 2학기 1단원 8~10차시
적용 기준: `/Users/yubyeongju/.agents/skills/humanizer/SKILL.md`

## 검토 범위

표지 목표와 생성형 표지 문구, 공용 방법 포스터의 안내, 여섯 문제의 질문·지시문·선택지·
자료 글·정답 설명, 흔적·그림자·특징 안내, 결과 발견 문구, 설정 버튼과 학생에게 읽히는
`aria-label`을 현재 원고와 실행 계약에서 확인했다.

## 문구 판정

- 자연도: **A**
- S1: 0건 / S2: 0건 / S3: 0건
- `살펴봐요`, `골라요`, `이어 볼까요?`, `함께 찾아요`처럼 한 문장에 한 행동만 남겼다.
- `주민 자치`, `주민 참여 예산`, `공공 기관 누리집`, `지역 자원봉사`는 이 차시의 교과 낱말이라
  유지하되, 바로 이어지는 사례와 설명으로 뜻을 풀었다.
- 초안의 `가장 알맞은 말을 선택해요`는 `하나 골라요`로, `참여 방법과 그 방법으로
  전할 수 있는 의견`은 `참여 방법과 알맞게 전할 의견`으로 줄였다.
- `자료 분석`, `핵심`, `적용`, `이벤트`, `토큰`, `오브젝트`, `게이트`, `힘`, `등급`
  같은 제작자 중심 표현은 학생 화면과 `aria-label`에 없다.
- 번역투 조사(`~에 대해`, `~을 통해`), 불필요한 피동형, 과도한 명사화, 같은 결말의
  기계적 반복을 피했다. 문장 끝은 학생용 `-요` 말투로 맞췄다.
- 생성형 선택지 그림의 대체 텍스트는 보이는 장면만 말한다. `정답`, `옳은 모습`처럼
  답을 먼저 알려 주는 말은 넣지 않았다.

## 의미 보존 6항

- [x] 수치·날짜·고유명사: 4학년, 2학기, 1단원 8~10차시, 6문제, PDF 48·49·54·62쪽과 인쇄 63·64·69·77쪽을 보존했다.
- [x] 인과관계 방향: 주민 참여가 골목길 안전과 마을 돌봄의 변화를 만든다는 방향을 유지했다.
- [x] 부정 표현: `전혀 살피지 않는`, `아무에게도 말하지 않아요`, `만나지 않게` 등 오답의 부정 의미를 뒤집지 않았다.
- [x] 직접 인용: 학생 화면에 출판사 글을 직접 인용한 별도 문장은 없다.
- [x] 핵심 주장·결론: 주민이 지역 일을 함께 살피고 누리집·자원봉사·투표 등 여러 방법으로 참여한다는 중심 뜻을 유지했다.
- [x] 격식 수준: 학생용 `-요` 말투와 짧은 행동 안내를 모든 문항에서 유지했다.

결론: 현재 문구는 4학년이 소리 내어 읽어도 자연스럽고, 윤문 뒤에도 지도서의 뜻과
문항 정답이 달라지지 않았다.
