# 소셜몬 바닷가 생활 탐험

6학년 2학기 사회 1단원 5~7차시를 묶은 5~7분 퀴즈다. 학생은 해안의 생김새와 양식업·항구·관광의 관계를 찾고, 관광과 자연환경을 함께 지키는 방법을 생각한다.

공용 `socialmon-quiz-lite-v1` 엔진, `socialmon-quiz-lite-profile-v2`, `socialmon-quiz-lite-contract-v3`을 사용한다. 6문제는 고르기와 이어 보기 두 가지 조작으로 구성된다. 지도 위치 버튼은 없다.

## 실행

```bash
node scripts/build-social-quiz.mjs _social_lessons/socialmon-6-2-u1-g03-coast-landform-journey
```

출처는 `SOURCE_LEDGER.md`, 학생 문구 점검은 `HUMANIZER_QA.md`, 최종 검증 기록은 `REPORT.md`에서 확인한다.
