# 소셜몬 함께 사는 약속

초등학교 3학년 2학기 사회 1단원 14~18차시를 묶은 5~7분 퀴즈다. 학생은 편견과 차별이 담긴 말이나 행동을 알아보고, 서로의 다른 모습을 존중하는 행동을 고른다.

공용 `socialmon-quiz-lite-v1` 엔진과 `socialmon-quiz-lite-profile-v1` 프로필을 사용한다. 이 폴더에는 차시별 문항과 출처만 둔다.

## 실행

`index.html`을 브라우저에서 연다. 태블릿 가로와 컴퓨터 화면을 지원한다.

## 문항 구성

- 자료 고르기 2문제
- 상황 고르기 2문제
- 나누기 2문제

문항 근거는 `SOURCE_LEDGER.md`에서 확인할 수 있다.
