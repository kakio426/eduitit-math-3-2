# 소셜몬 가계와 기업 이어 보기

6학년 2학기 사회 2단원 3~4차시를 다루는 6문제 퀴즈입니다. 가계와 기업이 일하고
소비하고 생산하면서 노동·소득·물건과 서비스를 주고받는 모습을 살펴봅니다.

고르기·이어 보기·나누어 보기 세 조작을 탭으로 사용하며, 가계의 생활 자료와 두 주체가
만나는 흐름 자료를 직접 읽습니다. 흔적 보상은 공용 `socialmon-trace-reveal-v1`이며
점수·등급·랭킹은 없습니다.

```bash
node scripts/build-social-quiz.mjs socialmon-6-2-u2-g08-household-company
node scripts/check-social-quiz.mjs socialmon-6-2-u2-g08-household-company
```
