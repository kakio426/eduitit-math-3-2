# 소셜몬 자연환경 맞춤 상품

6학년 2학기 사회 1단원 12~14차시를 묶은 5~7분 퀴즈다. 학생은 지역의 지형과 기후, 생활 모습을 조사하고 산지·눈 많은 곳·열대 지역에 알맞은 물건을 고른다.

공용 `socialmon-quiz-lite-v1` 엔진, `socialmon-quiz-lite-profile-v2`, `socialmon-quiz-lite-contract-v3`을 사용한다. 6문제는 고르기와 나누어 보기 두 가지 조작으로 구성된다. 지도 위치 버튼은 없다.

## 실행

```bash
node scripts/build-social-quiz.mjs _social_lessons/socialmon-6-2-u1-g06-environment-product
```

출처는 `SOURCE_LEDGER.md`, 학생 문구 점검은 `HUMANIZER_QA.md`, 최종 검증 기록은 `REPORT.md`에서 확인한다.
