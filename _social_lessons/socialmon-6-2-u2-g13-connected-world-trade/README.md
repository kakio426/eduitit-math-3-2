# 소셜몬 무역으로 이어진 세계

6학년 2학기 사회 2단원 17~20차시의 국가 간 상호 의존과 경쟁을 다루는 6문제
퀴즈입니다. 핵심 광물 협력, 여러 나라 부품이 모인 스마트폰, 첨단 기술과 무역
환경을 둘러싼 경쟁을 비교합니다.

고르기·이어 보기·나누어 보기 세 조작을 탭으로 풀며, 협력 기사와 스마트폰 부품,
첨단 기술 시장 자료를 직접 살펴봅니다. 국가 간 관계를 승패로 표현하지 않고 협력과 경쟁의 근거를
각각 확인하게 합니다.

```bash
node scripts/build-social-quiz.mjs socialmon-6-2-u2-g13-connected-world-trade
node scripts/check-social-quiz.mjs socialmon-6-2-u2-g13-connected-world-trade
```

근거는 `SOURCE_LEDGER.md`, 문항 판단은 `PLAN.md`, 현재 실행본과 QA는 `REPORT.md`에
기록합니다.
