# HUMANIZER QA — socialmon-4-2-u3-g14-city-features

기준: `humanizer` 스킬(`/Users/yubyeongju/.agents/skills/humanizer/SKILL.md`)과
`SOCIAL_SERIES_CONTRACT.md` 6절 학생 문구 계약.

태블릿 1024×768 브라우저 QA에서 4번 자료 문제의 세로 밀도가 높게 잡혀, 질문을 `부산의 교통 모습으로 알맞은 것은 무엇일까요?`로 줄이고 네 선택지를 한 줄 중심의 말로 다듬었다. 뜻과 정답 근거는 그대로 유지했다.
읽는 사람: 4학년 학생이 소리 내어 한 번에 읽고 이해할 수 있는가.

## 점검 대상

표지 목표, 표지 문구 아트의 한글, 문제 지시문, 자료 제목·본문, 선택지, 모둠 이름,
짝 카드, 한 줄 설명, 오늘의 발견, 학생에게 읽히는 대체 텍스트를 모두 읽었다.
방법 보기 세 단계와 결과 문구는 공용 프로필이 맡으므로 이 차시에서 바꾸지 않았다.

## 고친 말

| 처음 쓴 말 | 바꾼 말 | 까닭 |
| --- | --- | --- |
| `도시의 인구와 산업, 교통 특징을 자료에서 찾아봐요.` (원고 목표) | `사진과 지도에서 도시의 특징을 찾아봐요.` | 한 문장에 세 낱말을 나열해 숨이 찼다. 학생이 실제로 볼 물건(사진, 지도)과 행동 하나만 남겼다. |
| `도시의 특징을 종합적으로 설명해 볼까요?` | `도시의 특징과 설명을 이어 볼까요?` | `종합적으로`는 어른 말이다. 화면에서 하는 행동인 `이어 보기`로 바꿨다. |
| `다양한 산업이 발달했어요.` | `물건을 만들고 사고파는 일이 발달했어요.` | `다양한`은 AI가 자주 쓰는 말이고 4학년에게 뜻이 흐리다. 실제로 하는 일로 풀었다. |
| `교통망이 잘 갖추어져 있어요.` | `여러 곳으로 오갈 수 있는 시설이 많아요.` | `교통망`은 교과서에도 없는 어른 말이다. |
| `금융업이 발달한 곳이에요.` | `돈을 맡아 주거나 빌려줘요.` | 지도서가 금융업을 설명한 말 그대로를 학생 말로 옮겼다. |
| `도시의 인구 특성을 분류해 볼까요?` | `도시에서 볼 수 있는 모습을 두 모둠으로 나누어 볼까요?` | `특성`, `분류`는 제작자 말이다. 계약의 기본 행동어 `나누어 봐요`를 썼다. |
| `자료를 분석하여 알맞은 것을 고르세요.` | `사진을 자세히 보고 하나 골라요.` | `자료 분석`은 금지어다. 보고 고르는 행동만 남겼다. |

## 남긴 교과 용어

`인구`, `산업`, `교통`은 교과서 131~135쪽이 그대로 쓰는 말이라 지웠을 때 오히려 수업과 어긋난다.
그래서 3번 문항에서 이 세 낱말을 왼쪽에 두고, 오른쪽에 학생 말로 풀어 쓴 설명을 짝지어
학생이 낱말과 뜻을 같이 익히게 했다.

`부산광역시`, `전주시`, `버스 터미널`, `항구`, `공항`은 지도와 사진에 그대로 적힌 말이라 그대로 썼다.

## 최종 문구 점검표

| 점검 | 결과 |
| --- | --- |
| 한 문장에 행동 하나 | 통과. 지시문 6개 모두 `보고 골라요`, `눌러요`, `골라요` 하나로 끝난다. |
| 금지어 `탐구 역량`, `자료 분석`, `이벤트`, `토큰`, `힘`, `파워` | 0건 |
| 어른·제작자 말 `인구 밀도`, `산업 구조`, `교통망`, `도시 기능`, `종합적` | 0건 |
| AI 상투어 `다양한`, `효과적으로`, `중요한 역할` | 0건. `여러`로 바꿨다. |
| 번역투 `~에 대해`, `~을 통해`, `~되어진다` | 0건 |
| 한 문장 안 쉼표 두 개 이상 | 0건 |
| 평가하는 오답 피드백 | 0건. 오답에서도 다시 볼 자료만 한 줄로 알려 준다. |
| 도시를 다른 고장보다 좋게 말하는 문구 | 0건 |
| 가장 긴 학생 문장 | `많은 사람이 모여 살면서 여러 활동의 중심이 되는 곳이에요.` (25자). 소리 내어 한 번에 읽힌다. |

## 소리 내어 읽기 확인

6문제의 지시문 → 선택지 → 한 줄 설명을 차례로 소리 내어 읽었을 때 끊기거나 다시 읽어야 하는
문장은 없었다. 짝 카드와 모둠 이름은 모두 두 어절 안쪽이라 카드 안에서 줄바꿈 없이 읽힌다.
