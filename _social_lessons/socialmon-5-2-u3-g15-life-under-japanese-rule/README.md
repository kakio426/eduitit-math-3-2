- 문항 틀: `source-choice` 2, `match` 1, `choice` 2, `classify` 1
- 실제 조작: 고르기·이어 보기·나누어 보기
- 보상: `socialmon-trace-reveal-v1` (2·4문제 뒤 힌트, 마지막 소셜몬 공개)
- 점수·등급·순위·문제별 상자는 쓰지 않는다.

자료는 `5_2_사회_3_지도서.pdf` PDF 41·42·44쪽(인쇄 292·293·295쪽)에 근거하며, 실행 이미지·대체 텍스트·출처는 [`SOURCE_LEDGER.md`](SOURCE_LEDGER.md)에 기록했다. 식민 통치로 인한 불평등과 학교 통제를 장식적인 승패 표현으로 바꾸지 않는다.
