# 소셜몬 우리나라와 세계의 무역

6학년 2학기 사회 2단원 15~16차시의 우리나라와 세계 여러 나라의 무역 사례를
다루는 6문제 퀴즈입니다. 우리나라의 주요 수입품·수출품, 천연자원을 들여와
상품을 만들어 내보내는 흐름, 주요 쌀·원유 수출국을 자료로 살펴봅니다.

고르기·나누어 보기·이어 보기 세 조작을 탭으로 풉니다. 세 자료형 문항은 모두
`6_2_사회_2_지도서.pdf`의 실제 그림과 그래프를 좁게 잘라 사용하며, 생성 이미지는
표지 문구에만 사용했습니다.

```bash
node scripts/build-social-quiz.mjs socialmon-6-2-u2-g21-korea-world-trade-cases
node scripts/check-social-quiz.mjs socialmon-6-2-u2-g21-korea-world-trade-cases
```

근거는 `SOURCE_LEDGER.md`, 문항 판단은 `PLAN.md`, 현재 실행본과 QA는 `REPORT.md`에
기록합니다.
