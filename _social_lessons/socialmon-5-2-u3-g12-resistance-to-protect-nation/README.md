# 소셜몬 나라를 지키려 한 사람들

을사늑약의 영향과 항일 의병 활동을 지도서 자료에서 살펴보는 6문제 소셜몬 퀴즈다. 학생 흐름은 `cover → tutorial → play → result`, 기준 Stage는 `1280×800`, `16:10`이다.

- 문항 틀: `source-choice` 2, `match` 2, `choice` 1, `classify` 1
- 실제 조작: 고르기·이어 보기·나누어 보기
- 보상: `socialmon-trace-reveal-v1` (모든 답 뒤 흔적 1개, 2·4문제 뒤 힌트, 마지막 소셜몬 공개)
- 점수·등급·순위·문제별 상자는 쓰지 않는다.

문항 사실 자료는 `5_2_사회_3_지도서.pdf` PDF 14~15쪽(인쇄 265~266쪽)을 기준으로 했고, 자산별 검증은 [`SOURCE_LEDGER.md`](SOURCE_LEDGER.md)에 기록했다. 표지 제목 아트만 생성형이며 사실 근거로 사용하지 않는다.

빌드 후 최신 실행 증거는 `screenshots/qa-report.json`과 [`REPORT.md`](REPORT.md)에 기록한다.
