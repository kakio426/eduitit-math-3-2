# Humanizer 학생 문구 의미 보존 감사

검토일: 2026-08-12
대상: 4학년 2학기 1단원 1~3차시
적용 기준: `/Users/yubyeongju/.agents/skills/humanizer/SKILL.md`

## 검토 범위

표지 목표와 생성형 표지 문구, 방법 포스터의 안내, 여섯 문제의 질문·지시문·선택지·자료 글·정답 설명, 오답·정답 피드백, 흔적·그림자·특징 안내, 결과 발견 문구, 설정 버튼과 학생에게 읽히는 `aria-label`을 현재 실행본에서 확인했다.

## 문구 판정

- 자연도: **A**
- S1: 0건 / S2: 0건 / S3: 0건
- 한 문장에 한 행동만 남겼다. `살펴봐요`, `골라요`, `이어 볼까요?`, `나누어 볼까요?`, `함께 정해요`처럼 4학년이 바로 읽고 할 수 있는 말로 안내한다.
- `민주주의`, `자치회`, `공약`, `소수 의견`은 이 차시의 교과 낱말이라 유지하되, 자료·사례와 함께 보여 뜻을 짐작할 수 있게 했다. `민주주의를 돕는 태도`, `다시 생각할 태도`는 분류 버튼의 짧은 이름으로만 쓴다.
- `자료 분석`, `탐구 역량`, `이벤트`, `토큰`, `오브젝트`, `게이트`, `힘`, `파워`, `등급` 같은 제작자 중심 표현은 학생 화면과 `aria-label`에 없다.
- 불필요한 쉼표·콜론, 번역투 조사(`~에 대해`, `~을 통해`), 피동형, 과도한 명사화와 반복 결말은 확인되지 않았다. 문장 끝은 학생 화면 전체에서 자연스러운 `-요` 말투로 일관된다.
- 생성형 선택지 그림의 대체 텍스트도 그림의 장면만 말하며 정답을 먼저 알려 주는 표현은 없다. 그림은 뜻을 돕는 장식이고, 정답 판단은 지도서 자료와 선택지 글에 둔다.

## 의미 보존 6항

- [x] 수치·날짜·고유명사: 4학년, 2학기, 1단원 1~3차시, 6문제, PDF 11·12·13·19·20쪽과 인쇄 26·27·28·34·35쪽, 후보 소셜몬 이름을 보존했다.
- [x] 인과관계 방향: 건의함은 학생 의견을 듣고 학교 일에 반영하기 위한 것이라는 관계를 유지했다. 후보 공약을 듣고 투표한다는 순서도 유지했다.
- [x] 부정 표현: `한 사람의 생각만`, `아무도 의견을 말하지 않고`, `무시해요`, `말하지 못하게 해요` 등 오답의 부정 의미를 반대로 바꾸지 않았다.
- [x] 직접 인용: 학생 화면에 별도 직접 인용문은 없다.
- [x] 핵심 주장·결론: 민주주의를 여러 사람의 의견을 듣고 함께 정하는 방법으로 설명하고, 다른 의견 존중·소수 의견 살피기·함께 정한 일 실천하기를 유지했다.
- [x] 격식 수준: 학생용 `-요` 말투와 짧은 행동 안내를 모든 상태에서 유지했다.

## 실행본 확인

q5 분류 버튼이 비어 보이는 문제를 발견해 `quiz.json`의 두 모둠 필드만 공용 렌더러 계약인 `label`로 맞췄다. 보이는 문구와 의미는 바꾸지 않았으며, 이후 현재 실행본에서 `민주주의를 돕는 태도`와 `다시 생각할 태도`가 정상 표시되는 것을 눈으로 확인했다.

결론: 의미를 바꾸는 윤문은 필요하지 않다. 현재 학생 문구는 대상 학년이 소리 내어 읽어도 자연스럽고, Humanizer 기준과 교과 내용의 의미 보존을 함께 통과한다.
