# 소셜몬 오늘날 소식 전하기

초등학교 3학년 2학기 사회 2단원 23~26차시를 묶은 5~7분 퀴즈다. 학생은 오늘날 통신수단의 특징을 찾고, 달라진 생활과 새로 생긴 직업을 연결한다.

공용 `socialmon-quiz-lite-v1` 엔진과 `socialmon-quiz-lite-profile-v2`, `socialmon-quiz-lite-contract-v3` 계약을 사용한다. 이 폴더에는 차시별 문항과 출처만 둔다.

## 실행

빌드 뒤 `index.html`을 브라우저에서 연다. 태블릿 가로와 컴퓨터 화면을 지원한다.

표지는 공용 `communication-cover-v1` 배경과 차시 전용 생성형 문구 아트
`assets/cover-copy-v1-generated.webp`를 조합한다. 생성 원본은 같은 폴더의
`cover-copy-v1-source.png`에 보관한다.
