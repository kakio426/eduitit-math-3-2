# 소셜몬 경제 성장과 생활 변화

6학년 2학기 사회 2단원 8~9차시의 경제성장과 생활 변화를 다루는 6문제 퀴즈입니다.
의료·교육·생산 기술과 소득·문화생활이 달라진 모습을 찾고, 편리함과 환경 보호를
함께 생각합니다.

고르기와 이어 보기 두 조작을 탭으로 사용하며, 경제성장의 긍정적 변화와 함께 생길 수
있는 문제도 같은 자료에서 확인합니다. 생성 이미지는 표지·분위기·선택지 장식에만
쓰고, 사실 판단은 지도서 자료와 보기 글을 기준으로 합니다.

```bash
node scripts/build-social-quiz.mjs socialmon-6-2-u2-g10-growth-life-change
node scripts/check-social-quiz.mjs socialmon-6-2-u2-g10-growth-life-change
```
