# Humanizer 학생 문구 QA

## 분석 결과

- 대상: 표지 목표, 문제·안내, 선택지, 피드백, 결과의 오늘의 발견, 학생용 `aria-label`
- 감지된 패턴 요약: S1 0건, S2 0건, S3 1건
- 자연도 등급: A - 교과 용어 `지역문제`의 필요한 반복을 빼면 짧고 자연스러운 학생 말이다.
- 매우 짧은 문장이 많아 품사 비율 같은 장문 패턴 분석에는 한계가 있다.

S3 1건은 같은 차시에서 `지역문제`가 반복되는 점이다. 성취기준의 핵심 교과 용어이므로 다른 말로 바꾸지 않고, 한 문장 안에서 불필요하게 거듭 쓰는 부분만 줄였다.

## 적용한 수정

- 문제 1 지시를 `그림에서 지역문제를 골라요.`로 줄이고 선택지 문장도 한 가지 일만 말하게 다듬었다.
- `공사장 소음 때문에 주민들이 힘들어요.`를 `공사장 소음 때문에 주민들이 불편해요.`로 바꿨다.
- `지역문제와 생활에 끼치는 영향을 이어 볼까요?`를 `지역문제 때문에 생기는 일을 이어 볼까요?`로 바꿨다.
- `한 사람의 말만 듣고 바로 결론을 내려요.`를 `한 사람의 말만 듣고 바로 정해요.`로 바꿨다.
- 한 문장에 행동 하나만 남기고 안내 문장은 `골라요`, `나누어 볼까요?`, `이어 볼까요?`로 통일했다.
- 제작자 말인 `자료 분석`, `탐구 역량`, `이벤트`, `토큰`, `힘`, `파워`는 보이는 문구와 `aria-label`에 쓰지 않았다.

## 소리 내어 읽기 점검

- 문제 1: 그림을 본 뒤 고르는 행동이 바로 드러난다.
- 문제 2: `둘러보고`, `살펴봐요`, `이야기를 들어요`처럼 조사할 행동을 구체적으로 비교한다.
- 문제 3: 두 모둠 이름이 서로 겹치지 않고 각 항목이 짧다.
- 문제 4: 표를 봐야 답을 알 수 있고 자료 글이 답을 먼저 말하지 않는다.
- 문제 5: `영향` 대신 `때문에 생기는 일`로 풀었다.
- 문제 6: `조사할 질문` 대신 학생이 바로 할 수 있는 `알아볼 방법`을 고르게 했다.

## 의미 보존 자체검증

- 수치·날짜·고유명사: 6문제, 2·4문제 힌트, 지도서 PDF 12·13·16·18쪽 근거를 그대로 유지했다.
- 인과관계 방향: 지역문제에서 생활 불편·안전·건강 문제로 이어지는 방향을 유지했다.
- 부정 표현: 정답·오답의 가능/불가능 의미가 바뀌지 않았다.
- 직접 인용: 직접 인용문이 없다.
- 핵심 주장·결론: 개인의 일과 지역문제 구분, 자료 조사 필요성을 유지했다.
- 격식 수준: 4학년 학생용 해요체를 일관되게 유지했다.
