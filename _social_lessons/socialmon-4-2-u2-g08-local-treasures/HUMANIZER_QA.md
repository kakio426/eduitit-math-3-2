# Humanizer 학생 문구 QA

검토 기준은 `/Users/yubyeongju/.agents/skills/humanizer/SKILL.md`와 관련 어휘·번역투 점검표다. 뜻은 그대로 두되 4학년 학생이 소리 내어 읽기 쉬운 말로 고쳤다.

| 영역 | 확인한 문구 | 판정·수정 |
|---|---|---|
| 표지 목표 | `자연환경과 역사, 문화, 생산물에서 자랑거리를 찾아봐요.` | 교과 말 네 가지를 그대로 두고 행동을 `찾아봐요` 하나로 끝냄 |
| 자료 1 | `사진과 글을 보고 하나 골라요.` | `자료를 분석해 판단해요` 같은 어른 말을 쓰지 않고 화면 행동만 말함 |
| 개념 문항 | `자료에서 확인한 것을 하나 골라요.` | `근거 기반` 대신 학생이 하는 확인 행동으로 풀어씀 |
| 분류 문항 | `각 줄에서 알맞은 모둠을 골라요.` | 필수 드래그를 암시하지 않고 탭 동작을 바로 안내함 |
| 자료 2 | `그림 속 사람들은 무엇을 하고 있나요?` | 그림에서 바로 볼 수 있는 행동 하나를 묻고 배경 지식을 요구하지 않음 |
| 관계 문항 | `왼쪽을 누른 뒤 알맞은 오른쪽을 눌러요.` | 한 번에 누를 순서를 짧고 분명하게 말함 |
| 적용 문항 | `믿을 수 있는 소개를 하나 골라요.` | `신뢰성·출처 표기 원칙` 같은 어른 말 대신 학생 판단 기준을 씀 |
| 피드백 | `확인한 사실과 출처를 함께 적으면 믿을 수 있어요.` | 피동·번역투 없이 해야 할 행동과 까닭을 짧게 연결함 |
| 결과 | `자료에서 자랑거리를 찾고, 사진과 글을 알맞게 이어 보았어요.` | 학생이 한 두 행동을 구체적으로 되짚고 제작자 말을 쓰지 않음 |

문장마다 쉼표를 줄이고 `~에 대해`, `~를 통해`, `~에 기반해`, `가지고 있다`, 이중 피동, 불필요한 `~할 수 있다`를 쓰지 않았다. `핵심`, `생산량`, `출하`, `측정`, `등급`, `적용`, `이벤트`, `토큰`, `오브젝트`, `게이트`, `힘`도 학생 화면 문구에 없다. `자연환경`, `역사`, `문화`, `생산물`, `자랑거리`, `출처`는 수업에 필요한 교과 말이라 화면의 사진·글·모둠 행동과 함께 썼다.
