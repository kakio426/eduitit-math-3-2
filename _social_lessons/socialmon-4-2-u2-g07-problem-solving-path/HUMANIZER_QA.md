# Humanizer 학생 문구 QA

검토 기준: `/Users/yubyeongju/.agents/skills/humanizer/SKILL.md`의 의미 보존, 초등학생이 소리 내어 읽기 쉬운 문장, 번역투·어른 말 줄이기 기준.

| 영역 | 확인한 문구 | 판정·수정 |
|---|---|---|
| 표지 목표 | `자료에서 원인을 찾고 해결 방법을 이어 봐요.` | 행동 두 가지를 짧게 유지했고 `분석·도출` 같은 어른 말을 쓰지 않음 |
| 방법 안내 | `자료를 크게 살펴봐요.`, `답을 골라 확인해요.`, `흔적이 모이면 소셜몬이 보여요.` | 한 문장에 행동 하나, 소리 내어 읽기 쉬움 |
| 자료 문항 | `자료를 보고 하나 골라요.`, `표의 점수를 살펴보고 하나 골라요.` | `평가 기준` 대신 화면의 표·점수로 말함 |
| 관계 문항 | `왼쪽을 누른 뒤 알맞은 오른쪽을 눌러요.` | 탭 행동이 바로 보이고 불필요한 전문어 없음 |
| 순서 문항 | `먼저 할 일부터 차례로 눌러요.` | 드래그를 요구하지 않고 한 행동으로 안내함 |
| 피드백 | `자동차 수에 비해 주차 공간이 적어서 주차 문제가 생겼어요.` | 원인과 결과를 짧게 연결함 |
| 적용 문항 | `주민과 공공 기관이 함께 할 일을 하나 골라요.` | 주민과 공공 기관의 역할을 학생 말로 유지함 |
| 결과 | `자료를 살펴 원인을 찾고, 함께 해결할 방법을 이어 보았어요.` | `핵심·적용·등급·토큰` 같은 제작자 말이 없음 |

금지어와 어른 말 점검 결과: `핵심`, `생산량`, `출하`, `측정`, `등급`, `적용`, `이벤트`, `토큰`, `오브젝트`, `게이트`, `힘`을 학생 화면 문구에 사용하지 않았다. 사실 자료 출처 표면의 교과서 원문은 자료 이미지 안에만 남기고, 실행 문구는 학생이 바로 할 수 있는 행동으로 썼다.
