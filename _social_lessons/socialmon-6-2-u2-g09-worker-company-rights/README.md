# 소셜몬 일할 권리, 기업의 책임

6학년 2학기 사회 2단원 5~7차시를 다루는 6문제 퀴즈입니다. 근로자가 쉬고 안전하게
일할 권리와 기업이 자유롭게 활동하면서 사회와 환경을 생각할 책임을 함께 살펴봅니다.

고르기와 나누어 보기 두 조작을 탭으로 풀며, 지도서의 근로 실태·기업 책임 자료와
생활 속 안전한 일터 상황을 사용합니다. 일터를 승패나 가벼운 보상으로 꾸미지 않고
권리와 책임을 실제 행동으로 판단하게 합니다.

```bash
node scripts/build-social-quiz.mjs socialmon-6-2-u2-g09-worker-company-rights
node scripts/check-social-quiz.mjs socialmon-6-2-u2-g09-worker-company-rights
```

자료 근거는 `SOURCE_LEDGER.md`, 설계 범위는 `PLAN.md`, 실행 확인은 `REPORT.md`를 봅니다.
