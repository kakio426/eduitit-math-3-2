# Humanizer 학생 문구 의미 보존 감사

검토일: 2026-08-12
대상: 4학년 2학기 1단원 11~13차시
적용 기준: `/Users/yubyeongju/.agents/skills/humanizer/SKILL.md`

## 검토 범위

표지 목표와 생성형 표지 문구, 방법 포스터의 공용 안내, 여섯 문제의 질문·지시문·자료
제목·자료 글·선택지·정답 설명, 정답·오답 피드백, 흔적·그림자·특징 안내, 결과 발견
문구, 학생에게 읽히는 `aria-label`을 확인했다.

## 문구 판정

- 자연도: **A**
- S1: 0건 / S2: 0건 / S3: 0건
- 한 문장에는 행동 하나만 남겼다. `사진을 보고 하나 골라요.`, `왼쪽을 누른 뒤 알맞은
  오른쪽을 눌러요.`처럼 학생이 지금 할 일을 바로 알 수 있게 썼다.
- `주민 자치`, `주민 자치회`, `행정 복지 센터`, `한쪽 주차제`는 이 차시의 교과 낱말과
  자료 속 사실이라 유지했다. 문장 안에서는 사진, 의견 모으기, 계획 세우기, 필요한
  도움처럼 눈에 보이는 행동과 함께 설명했다.
- `핵심`, `생산량`, `출하`, `측정`, `등급`, `적용`, `이벤트`, `토큰`, `오브젝트`,
  `게이트`, `힘`, `파워` 같은 제작자·어른 중심 말은 학생 화면과 접근성 문구에 없다.
- 번역투 조사, 과도한 명사화, 피동형, 같은 뜻 반복, 지나친 쉼표와 콜론을 확인했으며
  학생 문구에서는 발견되지 않았다.
- 선택지 이미지의 대체 텍스트는 장면만 설명하고, 정답을 미리 알려 주는 평가 표현을
  붙이지 않았다.

## 표현을 고친 기록

| 초안에서 의심한 말 | 실행 문구 | 이유 |
| --- | --- | --- |
| 참여 전략을 수립해요 | 사진을 남기고 친구들의 생각을 모아요. | 처음 할 행동이 바로 보이게 함 |
| 행정적 지원을 제공해요 | 활동에 필요한 도움을 함께 마련해요. | 4학년 생활 말로 바꿈 |
| 주민 의견을 수렴해요 | 여러 의견을 모아 계획을 세워요. | 어려운 한자어를 행동으로 바꿈 |
| 자료를 분석해 정답을 선택해요 | 사진을 보고 하나 골라요. | 한 문장에 행동 하나만 남김 |
| 문제 해결 방안을 도출해요 | 문제에 맞는 참여 방법을 골라요. | 교사용 표현을 학생 말로 바꿈 |

## 의미 보존 6항

- [x] 수치·쪽수·고유명사: 4학년 2학기, 1단원 11~13차시, 6문제, PDF·인쇄·교과서
  쪽수와 기관 이름을 보존했다.
- [x] 인과관계: 주민이 의견을 모으고 계획하며 필요한 도움을 함께 마련해 지역을 바꾼다는
  방향을 유지했다.
- [x] 부정 표현: `혼자 시설을 바꿔요`, `조사한 내용을 모두 지워요`, `한 사람의 생각만`
  같은 오답의 부정 의미를 반대로 바꾸지 않았다.
- [x] 직접 인용: 학생 화면에 별도 직접 인용문은 없다.
- [x] 핵심 주장: 지역 문제를 살피고 여러 사람의 의견과 도움을 모아 참여한다는 내용을
  여섯 문항에서 유지했다.
- [x] 격식 수준: 학생용 `-요` 말투와 짧은 탭 행동 안내를 모든 문제에서 유지했다.

문항 6은 초안의 `참여 계획을 세워요`를 바로 정답으로 주는 대신 `사진을 남기고
친구들의 생각을 모아요`로 좁혀 첫 행동을 판단하게 했다. 의미 변화는 차시 목표를
벗어나지 않는 구체화이며, 6문항의 정답·오답 관계와 출처 사실은 모두 보존했다.

결론: 현재 학생 문구는 4학년이 소리 내어 읽어도 자연스럽고, Humanizer의 AI 문체
감지 항목과 의미 보존 기준을 함께 통과한다.
