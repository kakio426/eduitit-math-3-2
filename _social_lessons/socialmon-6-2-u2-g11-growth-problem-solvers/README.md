# 소셜몬 경제 문제 해결단

6학년 2학기 사회 2단원 10~12차시의 빠른 경제성장 문제와 해결 방안을 다루는 6문제
퀴즈입니다. 쓰레기·자원 낭비 문제를 자료에서 확인하고, 함께 실천할 계획과 학교에서
할 수 있는 행동을 고릅니다.

고르기·나누어 보기·이어 보기 세 조작을 탭으로 풀 수 있습니다. 지도서 72쪽의 기사와
90쪽의 실천 계획 자료를 사용하며, 생성 자산은 표지와 장식에만 사용합니다. 문제를
가볍게 경쟁시키거나 피해를 보상으로 만들지 않습니다.

```bash
node scripts/build-social-quiz.mjs socialmon-6-2-u2-g11-growth-problem-solvers
node scripts/check-social-quiz.mjs socialmon-6-2-u2-g11-growth-problem-solvers
```

출처 원장은 `SOURCE_LEDGER.md`, 제작 판단은 `PLAN.md`, 현재 실행 증거는 `REPORT.md`에
기록합니다.
