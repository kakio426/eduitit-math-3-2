# 소셜몬 지속 가능한 미래 약속

6학년 2학기 사회 3단원 10~14차시를 묶은 5~7분 퀴즈다. 학생은 개인·기업·국제기구의 노력을 자료에서 찾고 우리 반이 할 일을 고른다.

공용 `socialmon-quiz-lite-v1` 엔진과 `socialmon-quiz-lite-profile-v2`, `socialmon-quiz-lite-contract-v3` 계약을 사용한다. 표지는 지속 가능한 미래 테마 배경과 차시 전용 생성형 문구 아트를 조합한다. 지도서 자료 crop은 사실 근거로, 공용 선택지 그림은 글의 뜻을 돕는 장식으로만 쓴다. `map-hotspots`는 사용하지 않는다.

## 실행

빌드 뒤 `index.html`을 브라우저에서 연다. 태블릿 가로와 컴퓨터 화면을 지원한다. 문항 근거와 PDF 해시는 `SOURCE_LEDGER.md`에서 확인할 수 있다.

## 문항 구성

- 자료 고르기 3문제
- 바로 고르기 1문제
- 연결하기 1문제
- 상황 고르기 1문제

제작 잠금은 `PLAN.md`, 쪽별 근거는 `SOURCE_LEDGER.md`, 학생 문구 점검은 `HUMANIZER_QA.md`, 최종 검증 지문은 `REPORT.md`에 기록한다.
