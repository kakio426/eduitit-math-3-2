# 소셜몬 식민 통치 속 생활 읽기

1910년대 일제의 통치가 학교와 농민 생활에 준 영향을 지도서 자료로 읽는 6문제 소셜몬 퀴즈다. 학생 흐름은 `cover → tutorial → play → result`, 기준 Stage는 `1280×800`, `16:10`이다.

- 문항 틀: `source-choice` 2, `match` 2, `choice` 1, `classify` 1
- 실제 조작: 고르기·이어 보기·나누어 보기
- 보상: `socialmon-trace-reveal-v1` (2·4문제 뒤 힌트, 마지막 소셜몬 공개)
- 점수·등급·순위·문제별 상자는 쓰지 않는다.

문항 자료는 `5_2_사회_3_지도서.pdf` PDF 20~21쪽(인쇄 271~272쪽)에 근거하고, 이미지·문항별 사실·대체 텍스트·출처는 [`SOURCE_LEDGER.md`](SOURCE_LEDGER.md)에 기록했다. 식민 통치의 강압과 농민의 어려움을 승패나 희화화로 다루지 않는다.
