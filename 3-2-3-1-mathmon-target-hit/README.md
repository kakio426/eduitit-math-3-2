# 매스몬 표적 맞히기

에듀잇티 수학 게임 시리즈 3학년 2학기 3단원 1차시입니다.

- 학습: 원의 중심·반지름·지름 찾기
- 문제: 중심 4개, 반지름 3개, 지름 3개를 섞은 10문제
- 행동: 묻는 점이나 선분이 그려진 미니 원 1개 고르기
- 흐름: 첫 화면 → 방법 보기 → 문제 → 정답 확인 → 랜덤 표적 점수 → 결과
- 실행: `index.html`을 브라우저에서 열기

## 학습 화면

한 원에 네 후보를 겹치지 않습니다. 네 선택지는 각각 독립된 원 그림이며 점이나 선분의 위치 관계로 답을 판단합니다.

- 중심: 한가운데 점 / 테두리 점 / 치우친 안쪽 점 / 바깥 점
- 반지름: 중심에서 원까지 / 지름 / 중심을 지나지 않는 현 / 원에 닿지 않는 선분
- 지름: 중심을 지나 원의 양쪽까지 / 반지름 / 중심을 지나지 않는 현 / 원에 닿지 않는 선분

정답을 고르면 선택한 관계가 큰 원에 다시 그려지고 짧은 확인 문장이 나타납니다. 색은 선택 결과를 돕는 보조 신호로만 쓰며, 수학적 뜻은 점과 선분의 시작·끝 위치와 문장으로 전달합니다.

- 설명 2: 10문제·표적 점수 변화·마지막 표적 이름만 안내
- 랜덤 보상: 사건별 `reward-event-*-generated.webp` 6종
- 결과 상태 세트: 6장, 각 1280×800, 고정 제목과 `다시` 버튼 포함

문제 화면에는 큰 질문, 현재 원, 한 줄 지시 또는 피드백, 선택지만 둡니다. 점수 미터와 결과 등급은 문제를 푸는 동안 숨깁니다.

## 보상

중심 보상은 표적 점수 하나입니다. 문제를 끝낼 때 증가·감소·대량 증가·정중앙·0·무지개 중 하나가 나오며, 오답을 거친 문제는 감소 보상을 적용합니다. 최고 결과는 쉽게 나오지 않지만 한 판을 마쳐도 빈손으로 끝나지 않도록 구성했습니다.
