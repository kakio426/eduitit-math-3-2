# 매스몬 표적 맞히기

에듀잇티 수학 게임 시리즈 3학년 2학기 3단원 1차시입니다.

- 학습: 원의 중심·반지름·지름 찾기
- 문제: 중심 4개, 반지름 3개, 지름 3개를 섞은 10문제
- 행동: 묻는 점이나 선분이 그려진 미니 원 1개 고르기
- 흐름: 첫 화면 → 방법 보기 → 문제 → 정답 확인 → 랜덤 표적 점수 → 결과
- 실행: `index.html`을 브라우저에서 열기

## 학습 화면

한 원에 네 후보를 겹치지 않습니다. 네 선택지는 각각 독립된 원 그림이며 점이나 선분의 위치 관계로 답을 판단합니다.

- 중심: 한가운데 점 / 테두리 점 / 치우친 안쪽 점 / 바깥 점
- 반지름: 중심에서 원까지 / 지름 / 중심을 지나지 않는 현 / 원에 닿지 않는 선분
- 지름: 중심을 지나 원의 양쪽까지 / 반지름 / 중심을 지나지 않는 현 / 원에 닿지 않는 선분

네 선택지는 황동 레일로 이어진 하나의 2×2 표적 콘솔 안에서 비교합니다. 오답을 고르면 그 표적 위에 부족한 끝점이나 어긋난 중심 위치가 바로 표시됩니다. 정답을 고르면 고른 표적이 초록빛으로 확정되고, 같은 자리에 완성된 관계와 한 줄 확인 문장이 남습니다.

## 보상

중심 보상은 표적 점수 하나입니다. `점수 보기`를 누르면 3-2-2-4와 같은 공통 보상 모달이 열립니다. 처음에는 가려진 표적과 `열기` 버튼만 보이고, 연 뒤에는 사건 그림·실제 점수 변화·`다음` 버튼만 남습니다. `0`은 누적 점수를 지우지 않으며, 손해는 흔한 정답의 최소 증가량보다 크지 않습니다. 최종 결과 그림은 이 화면에서 쓰지 않습니다.
